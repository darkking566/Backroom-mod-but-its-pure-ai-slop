# 交接：現況與待辦

規則、環境、踩雷與定案方向在 `CLAUDE.md`；逐次細節看 `git log`。本檔維持 100 行內，完成的項目直接刪掉或濃縮成一句。

## 試玩

- 開遊戲：雙擊 `play.bat`（等同 `.\gradlew.bat runClient`）；改貼圖、模型、文字後跑 `.\gradlew.bat processResources`，遊戲裡按 F3+T；改 Java 要重開遊戲；改維度設定（`data/`）至少退回主選單
- 進後室：生存模式世界、允許指令；挖 1×1 深 3 格的坑站進去，對著坑壁頂端放兩次沙子埋住頭（創造模式不會觸發）
- 直接傳送：Level 0 `/execute in noclip_backrooms:level_0 run tp @s 3.5 33 3.5`（地板 y=32）；Level 1 `/execute in noclip_backrooms:level_1 run tp @s 32.5 33 41.5`
- 樓層進出：Level 0 → 1 待 1.5～3 分鐘後走進閃爍冒火花的牆；Level 1 → 2 往下的樓梯；Level 2 → 3 噴紅色「3」的門；各層說明在 `docs/企劃書/5-樓層/<層>/README.md`
- 光影：Iris 1.11.4、Sodium 0.9.2、Complementary Unbound r5.10；光影設定的 Resource Pack Support（RP_MODE）要改 labPBR；推薦設定在 `docs/畫面規範/光影設定/`

## 等使用者決定

- 相機要不要加「閃光燈開關」：關閃光就不引怪，要配代價（例如暗處照片減值）才不會變成白拿
- 拍照刷分：同一隻怪或同一次停電可重複拍、每張都全價；提議同一趟第二張半價、第三張起 5 點
- 相簿放進保險箱等於一格保護最多 24 張照片，要不要限制

- Blender 曲面網格 3 件試作看過後，要不要推廣到其他物品
- 畫面升級（128px 材質、立體踢腳板／燈具／門框）還沒親手試玩認可
- 「樓層工具包」備用企劃要不要做（使用者要先問朋友）
- 授權：Found Footage／SP-Backrooms 是 GPL-3.0，要不要整個模組改 GPL（與朋友一起決定）

## 尚未驗證

- `-Plevels=field` 不穩定（拍照功能前的版本跑 3 次也失敗 2 次）：應急燈、指引線、絆線、測繪信標偶爾失敗，原因還沒查

- 死亡保留測繪信標、`/meg relics` 查遺物方向（`core/trip/Relics`）：只有自動測試，還沒親手玩；掉在地上的東西是否撿得回來（原版 5 分鐘消失）沒查
- 掃描中死亡收回信標、第一件任務前 Level 0 不刷無盡之菌：只有自動測試（不刷菌那條沒有專門檢查），還沒親手玩
- 第一件任務原地接應（`/meg pickup`）：只有自動測試（沒檢查「不引怪」與實際送回），還沒親手玩
- 聽感：環境嗡嗡聲、Antigravity 加的音效
- 把 jar 裝進正式 Minecraft 啟動器；加進從未裝過本模組的既有存檔（先備份）
- 專屬方塊的聲音與挖掘手感；3D 方塊拿在手上、放在物品欄裡的樣子
- 出口：床與重生錨本身（測試用的是 `/spawnpoint`）
- 多人伺服器與其他模組相容性；實際 FPS（自動測試鎖在每秒約 20 格）

## 已知限制

- 任何主世界的窒息都會觸發（被沙礫活埋、被推進方塊也算）
- 坑洞深約 30 格，通常會摔死，物品留在坑底
- 出口的門與標誌不可破壞；創造模式拿去主世界放，生存玩家拆不掉
- 更新材質前探索過的區域維持舊方塊；新世界或沒去過的區域才是新材質
- 移除模組後，存檔裡的專屬方塊會消失
- 舊測試存檔 New World (1) 的舊區域地板在 y=1，走不到新地形，只能用指令離開
