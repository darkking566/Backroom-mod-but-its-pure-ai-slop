# 主樓層可破壞與收集物規劃（第一版，2026-11-24）

使用者的方向：每一層有自己能打掉、能收集的東西。像第 0 層什麼都可能有（電腦、手機、椅子、沙發……），敲掉會掉出**對應的物品**；同一種東西有完好的、壞掉的、**穿模的**版本；還有玻璃，之後在特定樓層（例如 Level 13 玻璃瘋狂）拿到稀有玻璃，Level 39 魔法森林拿到魔法材料。

這份只規劃**目前已經做好的樓層**：0、0.1、1、2、3。還沒做的樓層，等做到時再照同樣的格式補。

材料的名稱沿用 Gemini（Antigravity）的 [`docs/crafting/01_materials_and_props.md`](../crafting/01_materials_and_props.md)，兩邊不另取新名字；這份補的是「每一層擺什麼、敲掉掉什麼」。

---

## 一、三種掉落方式

| 種類 | 敲掉之後 | 例子 |
|---|---|---|
| **結構**（牆、地、天花板、燈） | 拆成材料（照 Gemini 的拆解表） | 壁紙 → 受潮碎壁紙、石膏粉；日光燈 → 燈管碎玻璃、紅銅線 |
| **物件**（家具、電器、雜物） | **掉出物品本身**，可以帶走、放回去、或在拆解台（Gemini 的 `salvage_bench`）拆成材料 | 電腦 → 「電腦」物品；沙發 → 「沙發」物品 |
| **異常物件**（穿模、發光、會動的） | 掉出「異常版」物品；要更好的工具；拆開有機會出異常材料 | 穿模的電腦 → 「穿模的電腦」，拆解小機率出 `reality_fragment` |

**同一種物件的三個版本**（以電腦為例）：

| 版本 | 樣子 | 多常見 | 拆解產出 |
|---|---|---|---|
| 完好 | 正常擺著 | 常見 | 最多、最完整 |
| 損壞 | 螢幕破、外殼凹 | 常見 | 少一些 |
| 穿模 | 一半卡進牆／地毯、貼圖閃爍或錯位 | 稀有 | 普通材料少，但有機會出異常材料 |

**層數越高，越稀有**：配合新的「第幾層」系統（見 [`docs/FLOORS.md`](../FLOORS.md)），走得越深，穿模版本和稀有材料出現的機率越高。

**分工**：
- Claude：決定每一層擺什麼、擺多少、擺在哪（樓層生成），以及敲掉掉什麼（掉落表）。
- Gemini：新物件與新物品的 3D 模型、貼圖，拆解台和合成表裡怎麼用。

## 二、第 0 層　大廳（The Lobby）

第 0 層本身空蕩蕩，物件都是「從現實掉進來的」：稀疏、單獨出現，常常卡在怪地方。

### 結構（已有，照 Gemini 拆解表）
壁紙、踢腳板、地毯、天花板磚、日光燈、紅室（Tier 3）、馬尼拉房間家具（桌、櫃、椅已會掉出本身）。

### 物件（新，要擺進第 0 層）

| 物件 | 版本 | 敲掉掉落 | 擺在哪、多常見 | 模型 |
|---|---|---|---|---|
| 桌上型電腦 | 完好／損壞／穿模 | 「電腦」本身（穿模版另成一種物品） | 隔間區的桌上（常見）；其他區偶爾單獨一台在地上；穿模版卡在牆角 | 新（Gemini） |
| 手機 | 完好／螢幕裂／穿模 | 「手機」物品（放下是地上的一小塊） | 地毯上，極少；穿模版一半陷進地毯 | 新 |
| 辦公椅 | 完好／穿模 | 「辦公椅」 | 隔間區、經典區偶爾 | 穿模版已有（`noclipped_office_chair`），完好版新 |
| 木椅 | 穿模 | 「穿牆木椅」 | 經典區、柱廳 | 已有（`noclipped_wood_chair`） |
| 沙發 | 完好／穿模 | 「沙發」 | 超大廳（幾張圍成一圈）、拱門區；穿模版陷進地毯 | 新 |
| 折疊桌 | 穿模 | 「半埋折疊長桌」 | 柱廳、經典區 | 已有（`noclipped_folding_table`） |
| 檔案櫃 | 穿模 | 「嵌牆鐵皮檔案櫃」 | 少，嵌在牆裡 | 已有（`noclipped_file_cabinet`） |
| 映像管電視 | 穿模 | 「卡牆老電視」 | 少 | 已有（`noclipped_crt_tv`） |
| 飲水機 | 穿模 | 「傾斜飲水機」，有時一起掉杏仁水 | 少 | 已有（`noclipped_water_cooler`） |
| 辦公室玻璃隔間 | 完好／破 | 完好掉「玻璃隔間」；破的掉「碎玻璃」 | 隔間區、拱門區的一些房間 | 新 |
| 流浪者殘骸 | — | 「殘骸」裡有隨機補給、日記殘頁、藍圖 | 全樓層，極少 | 已有（`wanderer_remains`） |

## 三、第 0.1 層　天頂站（Zenith Station）

這層原本就有很多站內物件（床、置物櫃、控制台、伺服器機櫃、跑步機、溫室……），大多已經會掉出本身。這層是「科技層」，電子零件比較多。

| 東西 | 敲掉掉落 | 備註 |
|---|---|---|
| 控制台、伺服器機櫃、壞控制台 | 掉本身；拆解出 `old_circuit_board`、`microchip`（這層機率比較高）、`copper_wire` | 已有 |
| 船員床、雙層床、置物櫃、衣櫃、桌椅、長凳 | 掉本身；拆解出 `synthetic_fabric`、`sheet_metal`、`metal_spring` | 已有 |
| 廚房：流理台、爐子、水槽、冰箱、碗盤、吊鍋 | 掉本身；冰箱拆出 `coolant_vial`、`copper_pipe` | 已有 |
| 健身房：跑步機、臥推架、啞鈴架、沙包 | 掉本身；拆出 `electric_motor`（跑步機）、`steel_gear` | 已有 |
| 溫室：水耕盆、水耕架、生長燈、水箱、垂藤 | 掉本身；水耕盆有機會掉種子或作物 | 已有 |
| 觀景玻璃（現在打不壞） | 改成要 Tier 2 工具才能拆，掉**強化觀景玻璃**（稀有玻璃） | 外殼板、艙壁仍然打不壞，免得把站打穿 |
| 發光球、軌道燈、樑燈 | 掉本身 | 已有 |
| 奇點、電漿、奇點外殼 | 打不壞（之後可做特殊事件給「奇點碎片」） | — |

| 東西 | 敲掉掉落 | 備註 |

## 八、之後的樓層（先記著）

- **Level 13 玻璃瘋狂**：整層都是玻璃，稀有玻璃的主要來源。
- **Level 39 魔法森林**：魔法木材、發光孢子、魔力結晶這類魔法材料，配合 Gemini 的魔法武器（`docs/crafting/06_weapons_magic_and_chests.md`）。
- 做到這些樓層時，照這份的格式補一節。

## 九、做的順序

1. 第 0 層：新物件（電腦、手機、沙發、玻璃隔間、完好辦公椅）請 Gemini 先做模型；同時我把 Gemini 已做好的 24 種穿模家具裡屬於第 0 層的先擺進去。
2. 第 1、2、3 層：先補「新規則」的掉落表，再擺 Gemini 的穿模家具。
3. 第 0.1 層：觀景玻璃改成可拆、補電子零件掉落。
4. 掉落的稀有度跟「第幾層」掛鉤（見 [`docs/FLOORS.md`](../FLOORS.md)）。
