# Level 3 興趣點（POI）企劃

- **來源**：[中文維基 latest:level-3](https://backrooms-wiki-cn.wikidot.com/latest:level-3)，2026-11-26 下載整頁原文讀過（含房間畫廊、異常、藝術品、8 頁筆記、Gamma 基地四次突破事件、三個分部、存儲設施、藍色救贖、錫拉殖民地、入口與出口）。
- **大方向**：照 [`docs/HORROR_ESCAPE_PLAN.md`](../../HORROR_ESCAPE_PLAN.md)，玩家是掉進後室的 M.E.G. 調查員。Level 3 的主線就是**找到 Gamma 基地**：路上是又危險、物資又多的迷宮，終點是整個後室最安全的地方。POI 照這條線排。
- **已經有的**（不重做，只加料）：六種大廳（發電室、鍋爐房、組裝線、聖所、車房、Base Gamma 據點）、三個勢力據點（B.N.T.G. 存儲設施、藍色救贖、錫拉殖民地）、鐵柵與柵門、熱點與警告牌、Base Gamma 路標（14 格內）、紫化磚、三種出口。程式在 `level3/`，大廳由 `Level3Plan.HallKind` 選、`Level3Halls` 擺東西。

## A. 大廳變化（既有大廳換版本）

| POI | 遊戲裡 | 互動 | 原文 |
|---|---|---|---|
| A1 被搬空的發電室 | 發電機只剩底座、地上有搬運拖痕與粉筆圈、M.E.G.／B.N.T.G. 噴漆編號、一台手推車 | 地上成堆杏仁水與火鹽（`fire_salt`） | 設備常被兩個組織搬走改作他用；杏仁水與火鹽大量出現 |
| A2 組裝線伏擊 | 輸送帶盡頭一整排杏仁水瓶群，旁邊陰影裡有 2～3 個武裝無面靈不動地等 | 玩家拿瓶子（或走到 5 格內）才發動 | 實體經常進入組裝線，而且「知道人類會來」 |
| A3 組裝線物資潮 | 輸送帶上偶爾送出整箱東西（電池、零件、杏仁水），每台有冷卻 | 右鍵出貨口拿一次 | 組裝線產出所有非單一、非限定層級的物品 |
| A4 聖所三像窗 | 彩繪玻璃改成三幅：天使、騎士、女人，周圍心形紋 | 純看 | 天使常與騎士、女人同時出現，有心形等愛情意象 |
| A5 聖所牌匾 | 天使台座上的古文字牌匾（每座聖所都一樣） | 右鍵看「看不懂的文字」；約 1/6 的聖所在牆角多一塊**不同的**牌匾樣本，可拓印成物品 | 主牌匾各聖所一致，另有 6 個額外樣本，交給 M.E.G. 有獎賞 |

A5 的拓印拿到 Gamma 基地（D）交給檔案員換錢，跟永久帳戶接起來。

## B. 鐵柵後的景（看得到、到不了）

鐵柵本來就打不壞也過不去，原文說柵欄後面的東西只在無人機失聯前拍到。做法：選被鐵柵擋住、另一頭是死路的通道，在死路那頭擺一個小場景，玩家只能隔著鐵柵看。

| POI | 擺什麼 |
|---|---|
| B1 柵後壁畫 | 白色畫布蓋住磚牆，畫著天使 |
| B2 柵後黑泥池 | 管子破了，黑泥流成一灘，泥裡有實體頭骨 |
| B3 風化女像 | 一尊希臘風格女性雕像，缺手、表面風化 |
| B4 地鐵零件 | 生鏽軌道、車輪、半截車門（後室地鐵的碎片） |
| B5 筆記本 | 地上攤開一本破筆記，看得到但拿不到（真正能拿的筆記在 C3） |
| B6 失聯的無人機 | **鐵柵這一側**：一台摔壞的 M.E.G. 無人機與遙控箱，旁邊柵欄後一點點閃著它掉下的燈 |
| B7 撈書的鉤竿 | **鐵柵這一側**：一根長金屬管斜靠在柵欄上，柵後地上有一本書的壓痕（呼應 B.N.T.G. 用金屬管把《後室終極食譜》鉤出來） |

規則：場景只放在柵後的死路裡，不動迷宮連通；B6、B7 擺在柵欄前不擋路。

## D. Gamma 基地本體（目的地）

原文的 Gamma 是「已知規模最大的人造建築」，三個分部加地下隧道，住幾千人。現在的 `BASE` 大廳只有 3×3 單元（18×18 格），撐不起來。建議：

- **現有 `BASE` 大廳改名為「M.E.G. 外圍哨站」**，保留行軍床、補給、交易，Level 11 的門照舊（存檔不受影響）。
- **新增真正的 Gamma 基地**：一座固定的大型結構，很稀少（例如每 4×4 張迷宮圖一座），整層的藍色路標改成指向**最近的 Gamma**、從遠處就開始出現（原文：方圓 100 英里都立了路標）。

由外到內：

| 區 | 內容 | 原文 |
|---|---|---|
| D1 外圍 | 走道上越來越多監視器（`security_camera`）與感測器、路標變密 | 外圍數百公尺內有攝影機與感測器 |
| D2 防禦牆 | 多層磚牆＋金屬牆、帶刺鐵絲網、通電柵欄（碰到會電）、入口上方狙擊台 | 磚牆與鈦牆、帶刺鐵絲網、電網、入口有狙擊手 |
| D3 檢查站 | 金屬探測門、指尖採血台；拿武器進去會被要求收起（不收就不開門） | 指尖採血看血色、金屬探測門、禁止攜帶武器 |
| D4 公共部 | 多層中庭、模擬日光的大燈、商店（用既有 `ShopRole`）、餐車與帳篷攤、電玩城、溫泉、鬼屋、街頭藝人 | 像大型商場；模擬日光；各類商舖與休閒設施 |
| D5 舊木造區 | 公共部一角是木材與簡易磚搭的舊區，有修補過的破洞（GB-01 肢團撞破木牆、GB-04 死亡飛蛾咬穿木材） | 舊區用木材和簡易磚；突破事件 |
| D6 住宅部 | 二樓：一排旅館式房間，床可設重生點；室內小鎮的一小段街 | 每位居民一間旅館式房間；人造室內城鎮 |
| D7 行政部 | 頂樓，鎖住；門外看得到伺服器機房的燈 | 禁止進入；運行資料庫的伺服器 |
| D8 地下隧道 | 隧道裡有加文·梅森的店（賣防蛾面具） | 隧道平時不開放；梅森的店在隧道內 |
| D9 出口 | 往 Level 11 的門、往 Level 4／5 的電梯（基地內就有一部） | 出口一節 |
| D10 存儲設施 | 緊貼 Gamma，從公共部可直接走進去：倉庫、當鋪、小博物館（展出《後室終極食譜》的玻璃櫃） | 存儲設施與 Gamma 相鄰、可經公共部進入；博物館有 Object 56 原件 |

Gamma 裡不生怪、不扣理智，是 Level 3 唯一的撤離／安頓點。D10 會讓現在獨立的 `BNTG_STORAGE` 大廳變成「Gamma 旁邊的那一座」，獨立的那種可以留著當分倉。

## 分批建議

| 批 | 內容 | 為什麼先做 |
|---|---|---|
| 1 | A1～A5、C1～C3 | 都在既有大廳與走道裡，不改迷宮；直接把原文最有名的東西放進去 |
| 2 | B1～B7、C4～C8 | 鐵柵後的景要先挑死路，跟迷宮生成一起改 |
| 3 | D 全部 | 最大的一批，要新的結構放置規則與路標改法；先跟使用者確認規模 |
| 4 | E | 錫拉的綁架要寫事件；藍色救贖只改外觀 |

每批的驗收照現有做法：單元測試（POI 不擋路、不懸空、鐵柵後的景只在死路、Gamma 與既有大廳不重疊）、`runClientGameTest -Plevels=3` 拍每個 POI 一張。

## 待決定

1. **Gamma 的規模**：做成上面這種多層大型結構（建議），還是維持現在 3×3 大廳只加料。
2. **Gamma 多稀少**：太常見就不恐怖，太少玩家找不到。建議每 4×4 張圖一座＋遠距路標。
3. **新模型**：屍鼠（C6）、U.E.C. 隊員、Gamma 居民的更多造型要不要請 Antigravity 做；不做就先用既有人形與陷阱方塊。
4. **筆記內容**：8 頁筆記用改寫的短句（建議，不照抄原文），還是只放「字跡太亂看不清」。
