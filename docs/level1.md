# Level 1：停車場（可居住區）

照 Backrooms Wikidot 的 Level 1（https://backrooms-wiki.wikidot.com/level-1）做的第一版。只借用通用的點子（水泥停車場、停電、補給箱），沒有搬 wiki 的原文或專有名稱。

程式全部在 `src/main/java/dev/noclip/backrooms/level1/`，Level 0 的檔案只動了三處：`BackroomsMod.java` 多一行註冊、語言檔與 `sounds.json` 加了新條目、挖掘工具標籤加了新方塊。

## 怎麼進來、怎麼出去

- **進入**：wiki 寫「在 Level 0 撐得夠久，找到一面閃爍的牆，把自己丟進去」。
  - 在 Level 0 待滿 3～5 分鐘後，附近（8～24 格、不在你正前方）會有一段牆開始閃爍、冒電火花、發出滋滋聲。
  - 直接走進去就會掉到 Level 1。牆用過、走遠（80 格）、離開 Level 0 或關掉伺服器時，會變回普通壁紙。
  - 落點一定在「停車區」的車道上，靠近你在 Level 0 的座標。
- **離開**：每塊白色走廊區裡都有一扇鐵製出口門，上面掛著 EXIT 標誌，附近的燈泡是綠色的。按右鍵回重生點（跟 Level 0 的出口一樣）。
  - Wiki 的正規出路是「往有管線和儀表的方向一直走，進入 Level 2」。Level 2 還沒做，所以先用出口門代替。

## 地形

整層切成 64×64 的區塊，同一個種子永遠長一樣：

| 區塊 | 比例 | 樣子 |
|---|---|---|
| 停車區 | 約 48% | 灰水泥地、黃色車位線、2×2 大柱子（底部警示斑馬線、部分漆著「P1」）、天花板橫樑 |
| 倉庫區 | 約 22% | 同樣的柱子，車位改成藍色鐵貨架 |
| 走廊區 | 約 30% | 白色水泥磚牆圍起來的窄迷宮（3 格寬、3 格高），有辦公室、儲藏室、磚牆房、軟墊房 |

- 天花板 5 格高；每 16 格一排燈，車道上方是水管，偶爾漏水，下面有積水和潮濕的地面。
- 走廊區的入口上方有**綠色逃生指示燈**（wiki：停電時找綠燈進走廊）。
- 區塊之間偶爾有水泥隔牆，牆上一定有開口；單元測試確認 160 個種子的每一格都走得到。

## 現象

- **停電（Flickering）**：有人在 Level 1 時，第一次在 1.5～4.5 分鐘後，之後每 3～6 分鐘一次。先有電流聲、燈閃三下，然後所有燈熄滅 15～45 秒。綠色逃生指示燈、綠燈泡和 EXIT 標誌不受影響。
- **補給箱**：大約每 1～2.5 分鐘在你背後 5～14 格的停車區地上冒出來，停電結束後也很可能出現。附近最多 3 個；沒人看著、你又離它 12 格以上時，會慢慢消失。右鍵撬開會噴出原版物品（麵包、烤馬鈴薯、蜂蜜瓶、線、紙、火把、時鐘、皮甲、羊毛，偶爾有鐵斧或金蘋果）。
- **聲音**：附近亮著的燈會嗡嗡響；水管不時傳來撞擊聲；遠處偶爾有低沉轟鳴；漏水的水管會滴水。全部借用原版或本模組已有的音效，各自有中文字幕。

## 指令

- 直接進 Level 1：`/execute in noclip_backrooms:level_1 run tp @s 32.5 33 41.5`
- 地板在 y=32，人站在 y=33。

## 改貼圖或模型

`python tools/make_level1.py`：重畫 `textures/block/level1/` 的全部貼圖（含光影用的 `_n`、`_s`），重寫 `models/block/level1/`、Level 1 的 blockstates 和物品模型，並輸出預覽 `docs/level1_textures.png`。不會動到 Level 0 的檔案。

## 這一版不做

怪物（wiki 說停電時最活躍，之後可以接）、wiki 的其他區域（Gild、Gothic 等）、據點、杏仁水等新道具、Level 2。
