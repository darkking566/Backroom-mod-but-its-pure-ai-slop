# 怪物

> 這一章說明後室裡有哪些怪物、多強、怎麼行動、會掉什麼。標示說明見 [企劃書總目錄](../README.md)。
> 還沒做的怪物、Boss 和寶箱的完整規劃在 [planned.md](planned.md)（原本 Gemini 的合成企劃第 02 份）。

## 設計原則（2026-11-25 恐怖方向）【定】

1. **怪物很難打，玩家很脆弱**。目標是無力感：比較好的做法通常是躲、逃、照規則應對，而不是正面打。
2. **可以殺，但很難**。被打到重傷的怪物會退回黑暗、躲起來回血，要殺死就得追進黑暗裡。
3. **照 wiki 原版設定**。每隻怪物都有它的弱點或應對方法，例如微笑者怕你不發光、不跑；肢團是瞎的，靠聲音找人。
4. RPG 等級不會讓你殺怪變快（見 [玩家能力值](../2-player/README.md)）。

## 強度

- **血量**【已做】：一般怪物是原本設計的 2.5 倍，Boss 是 3 倍，數字集中在 `monsters/Tuning.java`，要整體調整只改一個地方。
- **傷害**【已做】：沒有加。玩家的血砍半了（10 點），所以每一下等於痛兩倍。
- **遊戲難度**：原版的難度設定還會再乘一次怪物傷害（困難 ×1.5）。
- **重傷退回黑暗**【已做】（`monsters/Retreat.java`）：
  - 被玩家打到剩 30% 以下就不追了，往附近最暗的地方退。
  - 12 格內沒有玩家時，每秒回 1% 血，回到 60% 再回來。
  - Boss、中立的（無面靈、派對掃興客）、不會走路的（手臂）不會退。
- **層數越深越強**【未來】：見 [遊戲玩法：層數與難度](../1-gameplay/README.md#在後室裡層數與難度)。

## 出沒規則

- **目前**【已做】：每一層有自己的生怪程式。例如 Level 1 停電時從身後的走道出現獵犬、微笑者、手臂，Level 2 依明暗生出不同怪物。
- 原企劃書的 Level 0 規則【未來】：
  - 近處只有極少量的菌體，營造孤獨感；
  - 離降落點越遠、層數越高，才混入獵犬、微笑者和精英菌體；
  - 紅室一定有精英怪。
- **還沒做**：
  - 層數和水平距離讓怪物變多、變強；
  - 把還沒放進任何一層的怪物放到它們該在的樓層：派對客在 Level Fun、無盡之菌在 Level 0 的深處、第五層野獸在 Level 5。
