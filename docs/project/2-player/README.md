# 玩家能力值（RPG）

> 這一章說明玩家的血量、理智、四項能力值、等級、經驗，以及跟這些有關的介面與幻覺。標示說明見 [企劃書總目錄](../README.md)。

## 設計原則：RPG 要跟恐怖混在一起，要非常小心【定】

1. 等級高只會讓你**活得比較久**（血量、理智、回復），**不會讓你打得比較快**。
2. 就算滿級，一般怪物 3～4 下還是能殺死你。
3. 怪物可以殺，但很難；比較好的做法通常是躲、逃、照規則應對（見 [怪物](../4-monsters/README.md)）。
4. 經驗主要靠「活下來」拿，不靠殺怪，避免玩家跑去刷怪。
5. 武器、護甲（Gemini 做的）照「反制規則與控場優先」原則平衡【定】：日常求生與中高階裝備偏向針對怪物機制的反制工具、控場與環境／理智抗性；高火力與 7×7／9×9 終局裝備的舞台留給樓層 Boss 戰、深層極端區域與 30～60 秒撤離接應防守，不把一般小怪變成割草無雙（具體數值平衡待調）。
6. 不論怎麼配點，任何人都可以用任何武器，沒有硬性的職業限制（原企劃書）。

## 三條生存資源

| 資源 | 現在的數字 | 說明 |
| --- | --- | --- |
| 血量 | 10（5 顆心），主世界和後室都一樣【已做】 | 每 5 級多一顆心。後室裡吃飽自然回血只有原本的四分之一【已做】 |
| 飽食度 | 原版 | 完整保留原版飢餓，長時間探索要帶食物 |
| 理智 | 上限 50【已做】 | 自己的數值條，不佔飽食度。全黑處每秒 −0.26、昏暗處 −0.07、每隻附近的怪物 −0.15（最多 −0.5）；燈亮的地方會回。從滿到幻覺，全黑處約 2 分多鐘。主世界會慢慢回滿（但悲屍化排斥發作時會停，見 [遊戲玩法](../1-gameplay/README.md)） |

- **資源不足時**（原企劃書）【部分】：法杖施法要扣理智、有些重武器揮擊要扣血。不夠付的時候不會扣到死，而是直接不能用，畫面提示「資源不足」。法杖的理智鎖定 Gemini 做了，扣血武器還沒做。
- **理智低於 30% 會出現幻覺**【已做】：只有你自己看得到（只在你的電腦上畫，伺服器和隊友都沒有）：
  - 幻覺怪物從視野邊緣衝過來，揮刀砍它會尖叫化成黑煙；隊友看到的是你對著空氣揮刀；
  - 視野裡的隊友會變成後室怪物的樣子，名牌也不見。

## 四項能力值

升級拿點數，自己配。現在的效果【已做】：

| 能力值 | 每一點的效果 | 上限與規則 | 原企劃書還想加的【未來】 |
| --- | --- | --- | --- |
| 力量 STR | 近戰傷害 +0.2 | 最多 +3（點 15 點以上沒用） | 擊退距離、負重、重武器揮速 |
| 敏捷 AGI | 移動速度 +2.5%、攻擊速度 +4% | 沒有上限（使用者決定敏捷不動） | 衝刺耗體力、槍的裝填速度、後座力、精準度、暴擊 |
| 體質 VIT | 只加回血速度 | 越點越少，最多約 0.4 血／秒；**5 秒沒被打才開始回**（要躲起來才能補血） | 流血、中毒的時間縮短 |
| 理智 SAN | 只加理智回復與少扣一點 | 越點越少：回復最多 2.5 倍、少扣最多 40% | 法杖施法少扣理智 |

- 生命上限、理智上限**不靠加點**：每 5 級自動加一顆心（+2 血）和 10 點理智上限。

## 等級與經驗

- 升到下一級要的經驗：`60 + (目前等級 − 1) × 45`；每升一級拿 3 點能力點；新角色一開始有 3 點。
- 經驗主要靠活下來【已做】：

| 做到什麼 | 經驗 |
| --- | --- |
| 這一趟第一次到某一層（從主世界掉進去的第一層不算） | 40 |
| 被怪物追了 5 秒以上，之後 10 秒沒被追（「你甩掉了牠」） | 20 |
| 在新的據點安頓 | 50 |
| 活著回到地面 | 30＋每走一層 20 |
| 完成委託 | 報酬的五分之一 |
| 殺怪 | 後室怪物 12、原版怪物 4、Boss 150 |

- 還沒做：找到筆記、合成物品、完成商人任務也給經驗（原企劃書提的）。

## 介面【已做】

- **理智條**：在飽食度上方，每 10 點一個小圖示，上限多少就畫幾格；理智低於 60% 變紫、低於 30% 變紅並抖動，畫面四周出現暗角。
- **角色面板**：打開背包時在旁邊顯示等級、經驗條、理智、四項能力值和「+」加點按鈕；滑鼠移上去有說明。
- **層數**：後室裡左上角顯示「第幾層」，背包上方顯示「Level 幾 · 名稱」（見 [遊戲玩法](../1-gameplay/README.md)）。

## 之後要加的【未來】

- **隱藏能力值**（原企劃書）：用稀有寶箱或 Boss 掉的「禁忌知識卷軸」解鎖新的能力值欄位：
  - 幸運：家具與寶箱的稀有掉落、任務報酬；
  - 靈能：減緩掉理智、加強法術範圍；
  - 工程：槍有機率不耗子彈、拆解產出更多。
  
  卷軸物品 Gemini 做了，能力值欄位還沒接。
- **流派徽章**：原企劃書想做職業，但為了避免配錯點後悔，改成可以隨時換的徽章，給被動效果（例如法杖少扣理智、近戰扣血減半）。Gemini 的舊企劃有「法師」：吸收空氣裡的異常粒子快速回理智、施法扣理智。
- **成長型專武**：擊殺累積讓武器進化。Gemini 做了冷兵器、槍、法杖的三階進化：10 殺、30 殺，換外觀、加傷害。之後還想加鑲嵌強化和專屬技能。
- **保險箱**：死亡時保住少數物品的隨身格子，見 [遊戲玩法：死亡](../1-gameplay/README.md#死亡)。
