# 玩家能力值（RPG）

> 這一章說明玩家的血量、理智、四項能力值、等級、經驗，以及跟這些有關的介面與幻覺。標示說明見 [企劃書總目錄](../README.md)。

## 設計原則：RPG 要跟恐怖混在一起，要非常小心【定】

1. 等級高只會讓你**活得比較久**（血量、理智、回復），**不會讓你打得比較快**。
2. 就算滿級，一般怪物 3～4 下還是能殺死你。
3. 怪物可以殺，但很難；比較好的做法通常是躲、逃、照規則應對（見 [怪物](../4-monsters/README.md)）。
4. 經驗主要靠「活下來」拿，不靠殺怪，避免玩家跑去刷怪。
5. 武器、護甲（Gemini 做的）照「反制規則與控場優先」原則平衡【定】：日常求生與中高階裝備偏向針對怪物機制的反制工具、控場與環境／理智抗性；高火力與 7×7／9×9 終局裝備的舞台留給樓層 Boss 戰、深層極端區域與 30～60 秒撤離接應防守，不把一般小怪變成割草無雙（具體數值平衡待調）。
6. 不論怎麼配點，任何人都可以用任何武器，沒有硬性的職業限制（原企劃書）。

## 三條生存資源

| 資源 | 現在的數字 | 說明 |
| --- | --- | --- |
| 血量 | 10（5 顆心），主世界和後室都一樣【已做】 | 每 5 級多一顆心。後室裡吃飽自然回血只有原本的四分之一【已做】 |
| 飽食度 | 原版 | 完整保留原版飢餓，長時間探索要帶食物 |
| 理智 | 上限 50【已做】 | 自己的數值條，不佔飽食度。全黑處每秒 −0.26、昏暗處 −0.07、每隻附近的怪物 −0.15（最多 −0.5）；燈亮的地方會回。從滿到幻覺，全黑處約 2 分多鐘。主世界會慢慢回滿（但悲屍化排斥發作時會停，見 [遊戲玩法](../1-gameplay/README.md)） |

- **資源不足時**【已做】：法杖施法要扣理智、特定高風險近戰武器觸發特技要扣血（見 `BackroomsMagicItem`、`BackroomsMeleeItem`）。不夠付的時候不會扣到死（血量鎖定至少保留 > 1 點或特技代價），而是直接鎖定並畫面提示資源不足。
- **理智低於 30% 會出現幻覺**【已做】：只有你自己看得到（只在你的電腦上畫，伺服器和隊友都沒有）：
  - 幻覺怪物從視野邊緣衝過來，揮刀砍它會尖叫化成黑煙；隊友看到的是你對著空氣揮刀；
  - 視野裡的隊友會變成後室怪物的樣子，名牌也不見。

## 四項能力值

升級拿點數，自己配。現在的效果【已做】：

| 能力值 | 每一點的效果 | 上限與規則 | 進階戰鬥與生存效果【已做】 |
| --- | --- | --- | --- |
| 力量 STR | 近戰傷害 +0.2 | 最多 +3（點 15 點以上沒用） | 近戰擊退距離（遞減最多 +0.8 格）、重武器揮速補償（最多 +20%）；負重限制定案暫不實作 |
| 敏捷 AGI | 移動速度 +2.5%、攻擊速度 +4% | 沒有上限（使用者決定既有移速／攻速不動） | 槍械冷卻（最多 -30%）、擴散與後座力（最多 -35%）、暴擊率（最多 20%，1.35×）、衝刺耗飢餓減少（最多 -35%） |
| 體質 VIT | 只加回血速度 | 越點越少，最多約 0.4 血／秒；**5 秒沒被打才開始回**（要躲起來才能補血） | 中毒／凋零／流血等有害狀態時間縮短（遞減最多 -45%） |
| 理智 SAN | 只加理智回復與少扣一點 | 越點越少：回復最多 2.5 倍、少扣最多 40% | 法杖施法理智消耗減免（遞減最多 -35%，與武器進化乘法疊加） |

- 生命上限、理智上限**不靠加點**：每 5 級自動加一顆心（+2 血）和 10 點理智上限。

## 等級與經驗

- 升到下一級要的經驗：`60 + (目前等級 − 1) × 45`；每升一級拿 3 點能力點；新角色一開始有 3 點。
- 經驗主要靠活下來【已做】：

| 做到什麼 | 經驗 |
| --- | --- |
| 這一趟第一次到某一層（從主世界掉進去的第一層不算） | 40 |
| 被怪物追了 5 秒以上，之後 10 秒沒被追（「你甩掉了牠」） | 20 |
| 在新的據點安頓 | 50 |
| 活著回到地面 | 30＋每走一層 20 |
| 完成委託 | 報酬的五分之一 |
| 殺怪 | 後室怪物 12、原版怪物 4、Boss 150 |

- **額外生存經驗**【部分已做】：
  - 首次細讀現場檔案／筆記／馬尼拉手冊：`+15` 經驗（不重複領取）；
  - 向基地買家交付後室物資／證物：依成交額每 40 點 `+1` 經驗（單次最多 `+25`）。
  - **【待辦備忘（尚未接入 `crafting/`）】**：首次合成新物品給予經驗（因合成周邊目前交由 Claude 統一規劃，暫刻意不修改 `BackroomsStationMenu`，待合成表定案後再掛上）。

## 介面【已做】

- **理智條**：在飽食度上方，每 10 點一個小圖示，上限多少就畫幾格；理智低於 60% 變紫、低於 30% 變紅並抖動，畫面四周出現暗角。
- **角色面板**：打開背包時在旁邊顯示等級、經驗條、理智、四項能力值和「+」加點按鈕；滑鼠移上去有說明。
- **層數**：後室裡左上角顯示「第幾層」，背包上方顯示「Level 幾 · 名稱」（見 [遊戲玩法](../1-gameplay/README.md)）。

## 進階能力值與流派系統【已做】

- **隱藏能力值（LUK／PSY／ENG）**【已做】：角色面板頂部分為 `[能力 | 進階]` 雙分頁；使用 3 張禁忌知識卷軸永久解鎖對應欄位（初始即為 1 級），**已解鎖後重複撿到同種卷軸則免費 `+1`**（也可在 `[進階]` 分頁使用升級自由點繼續配點）：
  - **幸運（LUK）**：寶箱／怪物稀有掉落率最多 +35%（主題鎖定，保護證物）、委託信用點分紅最多 +25%、提升命運骰（`FATE_DICE`）高點數權重；
  - **靈能（PSY）**：額外減緩理智流失最多 20%（與 `SAN` 乘法疊加總計最多約 52%）、法術範圍／射程擴大最多 +35%；
  - **工程（ENG）**：槍械開火不耗子彈機率最多 30%、後室拆解／破壞 Mod 方塊額外產出材料最多 +40%。
- **流派徽章（方案 B，安全區切換）**【已做】：於 Level 0 **馬尼拉房間**找新 NPC「馬尼拉武人（`martial_master`）」花費 **6 枚遺失舊幣（`lost_old_coin`）** 永久兌換解鎖，不佔背包或飾品格；只限於安全區（前室／主世界或安頓床旁 16 格內）於 `[進階]` 分頁自由切換，進入深處後整趟鎖定。4 種徽章採「正面專長＋戰術代價」取捨：
  - **異常學者**：後室未被怪追擊時吸取異常粒子 `+0.25/s` 理智、法杖耗理智 `-20%`（代價：近戰物理直接傷害 `-15%`）；
  - **破陣重衛**：高風險近戰自傷 `-50%`、近戰擊退 `+25%`（代價：槍械基礎擴散 `+20%`）；
  - **戰術斥候**：開鏡移動大幅減輕緩速、槍械暴擊 `+10%` 與不耗彈 `+10%`（代價：非消音槍聲引怪半徑擴大至 `30` 格）；
  - **拾荒倖存者**：`VIT` 受傷回血啟動縮短至 `3.5` 秒（70 tick）、掉寶與拆解額外產出 `+10%`（代價：對怪物直接傷害 `-10%`）。
- **成長型專武**：擊殺累積讓武器進化。Gemini 做了冷兵器、槍、法杖的三階進化：10 殺、30 殺，換外觀、加傷害。之後還想加鑲嵌強化和專屬技能。
- **保險箱**：死亡時保住少數物品的隨身格子，見 [遊戲玩法：死亡](../1-gameplay/README.md#死亡)。
