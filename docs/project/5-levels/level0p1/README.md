# Level 0.1：天頂站（Zenith Station）

- **分類**：Level 0 的子樓層（第一個做出來的子樓層，共用做法見根目錄 `README.md` 的「子樓層」）
- **目前狀態**：已開放
- **資料夾與 Java 套件**：`dev.noclip.backrooms.level0p1`
- **維度 ID**：`noclip_backrooms:level_0.1`
- **出口登記鍵（`LevelExits`）**：`"0.1"`（父層 `"0"`）
- **原文**：[Backrooms 中文維基 Level 0.1](https://backrooms-wiki-cn.wikidot.com/level-0-1)（作者 CutTheBirch，譯者 Ambersight，生存難度 0）

## 原文怎麼說

一座被 Level 0 整個吞進去的巨大太空站：鋼鐵與玻璃的未來風，主體嚴重損壞。形狀推測是極大的球形殼體，殼厚到「幾乎能與數十條城市街區的寬度相當」，中間有一個巨大的空心區域。殼裡有大量臥室、廚房、健身室、水培溫室，用自動推拉門相連；機器人到處晃，少數還在清潔、烹飪。多數艙室燈亮、室溫，受損區域全黑，偶爾冷或熱到接近致死。天花板持續嗡鳴，有警報和自動廣播（「請保持冷靜」）。原文沒有任何怪物，也沒有據點；M.E.G. 勸人別為了材料進去，B.N.T.G. 有可靠的進入方法。入口幾乎不可能偶然遇到；出口回 Level 0，或「隨機切出」到 Level 1（偶爾回 Level 0）。

背景故事：科學家 Rhea Valpri 在天頂站做愛因斯坦–羅森橋（蟲洞）實驗，失敗後整座站被蟲洞吞進去，她最後獨自在黃色長廊裡哭。

## 遊戲裡怎麼做

### 形狀：真的做成一顆球

球心在世界座標 (0, 0, 0)，維度高度 1024（`min_y = -512`），是目前最高、最大的一層。

| 部分 | 半徑 | 內容 |
|---|---|---|
| 外殼 | 477–480 | 外殼板與肋條，不可破壞，什麼都出不去 |
| 殼體 | 189–477 | 約 290 格厚、每 8 格一層甲板（共 120 層上下），模組格子：每 16×16 一格，兩側是 4 格寬走廊，其餘是 10×10 的房間 |
| 隔艙壁 | 188–189 | 一格厚，有寬拱門 |
| 環廊 | 178–188 | 10 格寬、沿內殼彎曲的長街，內側整排窗 |
| 內殼 | 176–178 | 兩格厚，幾乎都是觀景玻璃 |
| 中央空洞 | 0–176 | 奇點、電漿圓盤、步道、大樑環、底部冷卻水湖 |

- **房間**：臥室、廚房、健身室、水培溫室、控制室、機房、儲藏室、空房、毀損房、氣閘室、實驗室。除了標準 10×10 格局（偶爾附帶內縮門廊），也加入三類空間變化：跨格合併大廳（`26×10` 長廳、`10×26` 深廳、`26×26` 廣場，並保留原本被吞掉的走廊穿堂門）、上下兩層打通的挑高室（`14` 格高附角落樓梯、二樓環形欄杆夾層與天橋）、以及室內深淺／高低變化（狹長通道、L 型轉角、隔間小室、下沉池、抬高平台、壁龕與天花板橫樑）；氣閘室、螺旋梯與水培大廳保持原樣不改。
- **自動門**：靠近 3 格內自動滑開，離開後自己關上（`ZenithDoors`）。
- **樓梯**：每 48×48 的角落有一座螺旋梯，繞著發亮的中柱，每圈上一層甲板，從最底到最頂都接得上（單元測試走過）。
- **中庭（水培大廳）**：約十分之一的 48×48×48 區塊是挖空的大廳，有苔蘚地、小池塘、開花杜鵑樹、天橋和懸浮光球，四周有欄杆走道和各層門。
- **損壞區**：48×48 格、3 層高一塊，燈全死、牆破、電纜垂下；其中一部分冷到會結霜（1 區），一部分熱到餓得快（2 區），待滿 30 秒開始減速（`ZenithClimate`）。
- **中央空洞**：四條「輻條」從赤道甲板的走廊筆直穿過環廊、內殼的門洞，伸到奇點外圈的步道；中心是近黑帶紫脈的奇點球（赤道一圈白熱邊）與白→黃→橘→餘燼紅四層的電漿圓盤，另有四個大樑環、一根從奇點貫穿到頂的繫纜、底部深 18 格的冷卻水湖（掉下去不會摔死）。
- **停電**（`ZenithBlackouts`）：每 6～10 分鐘一次，先警報與三次閃爍，天花板燈全滅 20～50 秒再恢復；樓梯芯、欄杆燈、光球、大樑燈自帶電不熄，原本就壞的燈不會被修好。
- **氣候與聲音**：嗡鳴、遠處警報、金屬嘎吱聲，以及不定時的站內廣播（聊天欄文字，內容來自原文的「請保持冷靜」和故事）。

### 出入口

| | 怎麼走 |
|---|---|
| **進來（找）** | Level 0 每個 1 公里見方的區塊，有一半會在一面牆裡藏一扇白色艙門（`station_hatch`），區塊載入時放進去，不影響能走的路（`ZenithEntrance`） |
| **進來（捷徑）** | B.N.T.G. 信標（`bntg_beacon`）：在 Level 0 右鍵使用，直接進站、信標用掉。合成：末影珍珠＋2 合金＋紅石（粉） |
| **出去** | 氣閘室中間的黃色門框（`yellow_doorway`），右鍵回 Level 0；氣閘室都在靠近外殼的地方 |
| **隨機切出** | 毀損房裡偶爾有「雜訊裂縫」（`static_tear`），右鍵：85% 掉進 Level 1、15% 回 Level 0 |

進站時落在最靠近玩家座標方向的氣閘室。

### 機器人

原文說房間裡有機器人（七足清洗機器人等），都是中立的環境角色，不攻擊。三種都用 Blender 建模（`tools/make_robots.py` 產生規格與貼圖，`tools/blender_robots.py` 在 Blender 5.3 的 bpy 組出 `art/robots/robots.blend` 與預覽圖），格式跟獵犬、居民一樣（BoxRig）：

| 機器人 | 長相與動作 | 出現在 |
|---|---|---|
| 七足清洗機器人（`robot_cleaner`） | 低矮圓頂、保險桿有警示條、七條小腳、前面一支滾刷（一直轉）、背後水箱；走路七條腿輪流動 | 走廊、一般房間 |
| 廚房機器人（`robot_chef`） | 輪子底盤、廚師帽、圍裙、琥珀色雙眼；站著時右手攪拌 | 廚房 |
| 壞掉的服務機器人（`robot_servant`） | 髒污生鏽、一隻眼壞掉一隻紅眼、左臂被扯斷露出電線、背後垂電纜；站著歪頭，偶爾抽搐，會冒火花 | 毀損房、冷／熱／暗的損壞區 |

牠們會閒逛、看你一眼，不會攻擊也不會鎖定目標；遠離玩家就消失。`ZenithRobots` 每 4 秒檢查一次，玩家附近少於 5 隻就在看不到的地方生一隻（可用 `/summon noclip_backrooms:robot_cleaner` 等自己叫出來，或在創造模式的「生怪蛋」頁籤拿三種機器人生怪蛋；蛋的圖由 `tools/make_robot_eggs.py` 產生）。

### 畫面質感

- 牆、走廊地板、甲板地板、天花板、寢室牆、廚房牆各有 3 個變體（`tools/make_level0p1.py` 的 `VARIANTED`，每個變體的髒污、污漬、凹痕不同），blockstate 隨機挑並轉 4 個方向，大片牆面不再是同一張圖重複；基本款也加了污漬、擦痕與凹痕（`wear`）。
- 寢室地毯與牆改暖色（米色牆、棕褐地毯、橘棕飾條），不再整層一片藍。
- 天花板燈亮度 14 → 13，維度的環境光色從飽和深藍 `#26324d` 改成中性灰藍 `#33373f`（霧色同步）；之前牆被染成藍灰就是這個設定造成的。
- 奇點：球改成近黑的深紫（亮紫色細脈），赤道多一圈白熱的邊，圓盤各層加了亮絲與暗隙，環距由 5 格改 6 格讓外圈的紅縮成窄邊（`ZenithLayout.cavity`）；截圖見 `screens/singularity.png`、`singularity_disc.png`。
- 暗房與損壞區：損壞牆也有 3 個變體（洞的位置與大小不同、其中一個沒有洞），整體提亮一點並加了淺刮痕，牆的形狀看得出來；垂下的電纜會冒火花發光（光照 6），是毀損房裡唯一的光（`screens/wreck.png`）。
- 冷區與熱區：冷區（zone 1）的房間牆有 2/3 是結霜的牆（`frost_wall`，白藍霜、冰晶、冰柱），熱區（zone 2）是焦黑的牆（`scorched_wall`，黑牆上發橘光的裂縫，光照 3），其餘 1/3 還是撕開露出電纜的損壞牆；暗區（zone 3）維持損壞牆。地板同理：冷區一半以上的板是結冰的地板（`frost_floor`），熱區是焦黑發橘光的地板（`scorched_floor`，光照 2），另有 1/4 是原本的磨損地板。天花板也一樣：冷區 3/4 的板是結霜的天花板（`frost_ceiling`），熱區是焦黑的天花板（`scorched_ceiling`），燈照舊（大多壞掉）。六種新方塊各有 3 個隨機變體（`screens/zone_cold.png`、`zone_hot.png`）。
- 四種原文房間的擺設（`tools/make_level0p1_props.py`，18 個新方塊，只動自己的檔案）：寢室（上下舖、牆上相框、開門衣櫃、辦公桌與桌上私人物品）、廚房（水槽、冰箱、吊掛鍋具、桌上疊盤）、健身室（臥推架、沙包、牆鏡、飲水機、墊子堆）、水培溫室（栽培架、植物燈、水箱、垂藤）。每種房間依房號選擇配置，十字通道不擋。實機截圖已看過，近照角度還沒逐件補。
- 第二批細節（同一支 `make_level0p1_props.py`）：運作中的走廊天花板每 16 格一個廣播喇叭（`ceiling_speaker`），站內廣播時附近喇叭冒音符；垂下的電纜偶爾噴電火花並發出聲音、排熱孔冒煙（`ZenithAmbience.details`，在玩家周圍隨機抽樣，不整區掃描）；冷區走廊有冰柱（`icicles`）與積冰（`ice_drift`），熱區走廊有熔渣堆（`slag_pile`，光照 5）與發光排熱孔（`heat_vent`，光照 8），四種都可穿過；拆解材料：電纜掉銅錠與紅石、控制台掉紅石與鐵粒、壞控制台與伺服器機櫃另有金粒、鐵／銅錠與機率掉合金（B.N.T.G. 要的材料）。近照見 `screens/detail_*.png`（`NOCLIP_ONLY=details`）。注意：`make_level0p1.py` 會把這四個方塊的掉落表蓋回「掉自己」，之後要再跑 `make_level0p1_props.py`。
- 第三批（從原文背景故事延伸，不是原文的關卡機制）：新增第 11 種房間「實驗室」（`Room.LAB`，約 4%）：一角有發紫光的橋接發射線圈（`bridge_coil`，光照 12），一角是伺服器機櫃，牆邊是桌子與控制台，牆上掛停在 00:00 的倒數螢幕（`countdown_screen`，也掛在控制室牆上）；每個氣閘室（黃色門框旁）有一角放 Rhea 的研究筆記（`research_notes`，右鍵讀一頁，共 4 頁，內容來自原文背景：橋接實驗失敗、倒數停在零）與她的實驗袍（`lab_coat`）。近照 `screens/room_lab.png`、`detail_countdown.png`、`detail_notes.png`。
- 窗外的「房間海」（原文背景故事：Rhea 從外窗看見無盡昏暗房間組成的建築海洋，把空間站包在中間）：外殼現在有外窗（`ZenithLayout.window`，4 格見方的片、只開在後面有走廊或房間可站的地方，用不可破壞的觀景玻璃），外殼外 60 格起到半徑 740 為止生成 Level 0 的房間堆（`ZenithLayout.sea`）：每間 11 寬 3 高、一層的地板就是上一層的天花板、用 Level 0 的壁紙、地毯與日光燈、約 1/5 的房間還亮著燈；有整片缺失的洞與斷崖、牆上偶有門洞。全部用純函式算、只在有人靠近外殼時才會生成。近照 `screens/detail_outside.png`：透過窗只看得到微弱的黃色牆面，因為外面本來就暗，加上攝影機濾鏡更暗。
- 注意：重跑 `make_level0p1.py` 會重畫全部貼圖，其中不少跟已提交的版本有差（可能有人手改過），只想動這幾張時，跑完請用 git 還原其他貼圖。
