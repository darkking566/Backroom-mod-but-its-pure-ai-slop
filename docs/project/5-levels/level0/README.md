- **分類**：主樓層（核心）

## 一、定位與恐怖基調【定】

- **核心體驗：純心理恐怖，不放常駐實體怪物**。
  - 呼應後室原設的「孤立效應」與教學首層定位：Level 0 **不生成獵狗、笑魘、竊皮者或細菌等主動追殺怪物**（除非本趟出勤詞綴特別介入，或玩家誤觸極端陷阱／紅室困死機制）。
  - 緊張感來源改由 **建築尺度壓迫感、日光燈明暗與嗡嗡聲、理智流失、陰影幻覺、空間移位（Edge Shift）、環境微小事件、以及陷阱與迷路風險** 共同堆疊，讓玩家「明明什麼怪物都沒看到，卻一直覺得背後有東西」。
- **Wikidot / Fandom 共通設定**：無盡延伸的潮濕黃色壁紙商辦迷宮、發霉黏腳地毯與 60Hz 嗡嗡作響的冷白日光燈（約一半亮、一半壞燈，燈下一圈光、燈之間暗）。

## 三、空間架構：方案 C「每趟有限高密度扇區＋非歐幾里得邊界無縫回繞」【定】

解決「純無限大地圖內容被過度稀釋、逛 10 分鐘都長一樣」與「純固定地圖跑 3 趟就背板」的兩難：

1. **有限大小的高密度探索舞台**：
   - 配合現有出勤落點（`Expedition`），每一趟在落點周圍劃定一座**約 `280×280`～`350×350` 格**的有限迷宮扇區（以當趟種子決定佈局，每趟皆不相同，不會背板）。
2. **非歐幾里得邊界無縫回繞（不放空氣牆）**：
   - 玩家往同一方向走到扇區邊界時，不設實體邊界牆或提示阻擋，而是在邊界轉角走廊觸發**無縫空間回繞**（搭配一次輕微日光燈閃爍或低頻嗡鳴），平順接回扇區另一側的對應通道。
   - 體感上依然是「永遠走不到盡頭的迷宮」，但實際探索範圍集中，所有精心設計的地標與事件都能在一趟 10～20 分鐘的遊玩內穩定體驗到。
3. **每趟必出地標配額（確定性保證）**：
   每座高密度扇區在生成時**保證包含**：
   - **主線必出**：至少 1 條往 `Level 1` 的明確路線（閃爍牆之外，另保底 1 處往 Level 1 的實體結構通道）。
   - **大型地標（保底 4～5 種以上）**：至少 1 座「下層可逃生 Pitfalls 陷阱大廳」、1 座「十字大柱廳／超大廳」、1 座「暗區積水＋配電室」、1 座「多層樓梯複合體」、1 座「M.E.G. 臨時隔離勘查點」。
   - **稀有亮點（大幅調高合理遇見率）**：提高馬尼拉房間、紅室邊緣、超大挑空區的出現率，不再動輒相隔上千格。
   - **多樣化跨層出口**：每座扇區隨機抽選 **4～7 條不同載體的異常出口**（海報、窗戶、地下通道、鏡子、異色牆／地毯等，見第六節）。


4. **真正的環面：看不出接縫的有限場景【已做，2026-11-27】**（`level0/Level0Space`、`StageLoop`）
   - 原本的做法只把玩家傳回對面（生存與冒險模式才有），邊界外看到的是隔壁另一塊場景，傳送時四周會突然變樣；旁觀者與創造模式完全不循環。
   - **現在**：世界本身週期重複。每 5×5 塊場景（1500×1500 格）為一區，區內每一塊都是正中間那塊的複製（生成器寫進世界的方塊是 `blockAt(template(x), y, template(z))`；計畫本身 `blockAt` 不變，單元測試照舊）。玩家（任何模式）一律待在區的中央場景，跨過邊緣就**剛好平移 300 格**、面向與速度不變；因為兩邊方塊一模一樣，看不出被移動。中央場景四周各有 600 格的複製品，視野拉到最遠（512 格）也看不到盡頭。不同趟落在不同區，地圖仍各自不同。靠近邊緣 48 格時先載入對面的區塊。
   - 跟著改的：落點一律選在中央場景（`Level0Arrival`）；紅室判斷用範本座標；迷宮變形（`EdgeShift`）以原始格為準，同時改寫附近每一份複製，任何一份被看著就不變形；閃爍牆只開在中央場景；Level 0.1 的白色艙門改成「每兩塊場景藏一扇」，位置從計畫算出，每份複製都在同一處；空間測繪信標的距離用「走過的距離」計算（往東跨過邊緣一次算 300 格）。
   - **給擺放的人**（2026-11-27 起是 Claude）：之後要擺進第 0 層的東西（電影版家具等），請在生成器裡依範本座標決定（像牆一樣由 `worldBlockAt` 那一層產生），或放在中央場景時同時放進每一份複製；只在區塊載入時照區塊掃描擺放的做法，複製品會對不上（300 不是 16 的倍數）。
   - **完整鏡像【已做，2026-11-27】**（`Level0Mirror`、`Level0Ghosts`、mixin `LevelSetBlockMirror`、`TrackedEntityTorus`）：
     - 方塊：第 0 層任何方塊改變（敲牆、放東西、燈熄掉）同時寫進所有已載入的複製品，並記在存檔裡，之後才載入的複製品會補上。
     - 東西：怪物、掉落物、箭等跨過邊緣，也跟玩家一樣平移回中央場景。
     - 看到另一頭：伺服器照「環面上的距離」把附近的玩家、怪物、掉落物送給客戶端；客戶端在邊緣外畫出它們的分身（看得到、會動、拿著同樣的東西，但打不到、碰不到；跨過去就會遇到本尊，站在分身原本的位置）。
     - 還沒鏡像：音效、粒子、方塊實體的內容（例如箱子裡的東西、告示牌字）。

   - 房間之間加入 2～3 格高低差的寬階梯與扶手，打破全層平面單調感。

7. **假門長廊與牆面異變**：
   - 一排外觀完全相同的門（推開多為實牆、少數藏密室或空間轉向）；局部壁紙剝落露出水泥底層。

## 六、Level 0 多樣化異常出口系統（《狐霖的後室》＋ Wikidot／Fandom）【定】

### 1. 統一演算法：模糊線索 → 互動觸發 → `LevelExits`
- **不侷限於門**：出口以海報、牆上窗戶、地下鐵格柵／通風口、空心牆、巨型鏡子、異色地毯、異常階梯、光影走廊與少數主題門框等多元形態融入場景。
- **模糊環境描述（不直接劇透樓層編號）**：
  - 玩家靠近或右鍵檢視出口物件時，僅顯示 1～2 句具象但模糊的敘述（**感知高**會多一句更關鍵的細節）；玩家必須自己從線索判斷「要不要破壞、撕下、鑽進去或跨過去」。
  - 例：**1980 阿帕拉契海報**——牆上貼著一張褪色受潮的旅遊海報，隱約畫著霧氣瀰漫的松林與木造山莊，底部殘字寫著「……1980 冬季休業……」；玩家**右鍵撕下或左鍵打掉海報**後，眼前霧白一閃即被傳送至 `Level 161`（阿帕拉契的荒涼）。
- **接線與未開放保護**：
  - 所有出口統一呼叫 `LevelExits.use(player, 出口鍵)`；目標樓層尚未實作時，**物件與模糊描述照常生成**，觸發互動後提示「另一側的空間尚未穩定成形（Level X 尚未開放）」且不消耗、不傳送；未來目標層完成並註冊 `LevelExits.open(...)` 後自動全部接通。
- **出現權重演算法**：
  - **保底主線**：每趟高密度扇區必定生成 `Level 1` 入口（既有閃爍牆＋1 處實體結構通道）與極稀有 `EXIT` 撤離門（接應倒數回前室研究所）。
  - **動態支線池**：每座扇區依「層級偏離度／稀有度權重」從下方異常出口池中抽出 **4～7 條**分佈在不同地標與走廊，確保玩家「在抵達 Level 1 之前，就能撞見各種意想不到的非門出口」，且每一趟出現的組合不同。

### 5. 給擺放的人（2026-11-27 起是 Claude）

- 方塊常數：`FilmProps.<名稱>`；所有物件：`FilmProps.all()`（id → Block）。
- **朝向**：`FACING` 是物件正面看出去的方向；多格物件的寬往正面的右手邊（`FACING.getClockWise()`）、深度往後（`FACING.getOpposite()`）延伸，跟 `MultiPartPropBlock.occupiedPositions` 一樣。
- **多格物件**（`MultiPartPropBlock`）：放主方塊後，照 `Level0Props` 的做法補 `PropPartBlock` 並設好主方塊位置（或呼叫 `setPlacedBy`）。
- **單格物件**（`FilmPropBlock`）依 `mount()`：`FLOOR`、`SMALL` 放地板上一格；`LOW`（地毯、床墊、錄影帶）平放、可走過、模型可能超出自己那格；`WALL` 放在牆前那格，`FACING` 朝離開牆的方向；`CEILING`（吊牌、吊燈）放在天花板下一格。
- 生成器只放方塊狀態；方塊實體在區塊載入時補建（`BackroomsProps.register` 已處理），不用另外處理。
- 驗收：`gradlew runClientGameTest -Plevels=film`（每個物件都有方塊實體、模型、貼圖；錄影帶掉落與標籤；沙發整組打掉；收購商收錄影帶）。
- 重做物件：`py tools/film/prints.py tools/film/prints` → Blender `tools/film/make_film_props.py` → `tools/film/make_film_icons.py` → `py tools/film/make_film_data.py`（步驟寫在 `make_film_data.py` 開頭）。
