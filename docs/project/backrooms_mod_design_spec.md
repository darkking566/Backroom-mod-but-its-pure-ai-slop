## 1. 專案總覽與技術定位

* **開發路線**：**100% 原創獨立 Mod**（不使用現成大型玩法模組拼裝，確保探索新鮮感、數值完全掌控，以及未來擴充至 300 個以上樓層與新裝備時的維護彈性）。
* **允許引入的隱形底層函式庫（Library Dependencies）**：
  * **GeckoLib**：處理所有自製 3D 武器（槍械換彈、法杖發光）、後室實體的骨骼與動作動畫。
  * **Curios API**：提供額外飾品與徽章欄位。
  * **JEI / EMI**：提供玩家查詢超大型合成表、拆解配方與樓層掉落物來源。
* **核心玩法融合定位**：
  * **《胡霖的後室》**：雙軌難度（Level 編號 vs. 累積層數 Depth）、探索撤離、廢料回收與藍圖解鎖。
  * **《非生物因素 Abiotic Factor》**：辦公雜物拼裝硬核科學求生裝備、分階密碼門駭客器、工具分級拆解家具。
  * **《異星工廠 Factorio》**：標準化工業中間零件、三色電路階梯、研究瓶（Science Packs）科技樹、插件晶片。
  * **《星露谷物語 Stardew Valley》**：四階星級品質系統、主世界加工致富設施、檔案收集包（Bundles）、封存盲盒（晶球）。
  * **《Minecraft》**：主世界大本營經營、超大型蜘蛛網合成台、原版物資融合與原版維度（地獄、終界）後室化。

## 2. 核心遊戲迴圈與世界結構

### 2.1 主世界（Overworld — 絕對安全大本營）
* **功能定位**：玩家的永久據點與局外成長基地。
* **核心設施**：
  * **超大型蜘蛛網合成台**（主軸製作設施）。
  * **主世界加工設施**：垃圾回收拆解機、異常蒸餾桶（釀造高價消耗品與貿易品）、異常研究終端（消耗研究瓶解鎖配方）、後期異常晶體複製機。
  * **角色與收集設施**：屬性升級祭壇、異常檔案修復板（收集包）、次元保險箱擴容介面、古物與圖鑑展示系統。
  * **NPC 總部**：原版風格交易商人、封存盲盒撬鎖服務。
* **層數重置規則**：每次從主世界重新切入後室，玩家必從 **Level 0（`Depth = 1`）** 開始，累積層數重置。

### 2.2 雙軌與雙軸難度系統（核心引擎規則）
系統必須嚴格區分 **樓層編號（Level ID）** 與 **累積層數（Depth）**：

1. **垂直難度（Depth 層數）**：
   * 玩家每切換一次樓層（**包含重複回到曾經走過的 Level，例如從他層繞回 Level 0**），`Depth + 1`。
   * **實例刷新**：再次進入同一 Level 時，必須將玩家傳送至該 Level 的**新隨機座標（或重置實例）**，確保場景家具與寶箱為全新狀態。
   * **難度與回饋**：Depth 越高，怪物生成密度、血量、攻擊力越強；同時寶箱與家具的掉落數量、星級品質權重、稀有物資機率大幅上升。
2. **水平難度（Horizontal Distance）**：
   * 每個 Level 近似無限大（Minecraft 邊界）。
   * **基準點防呆規則**：水平距離**不可**以世界原點 `(0, 0)` 計算，必須以**「玩家本次進入該樓層的降落點（Entry Spawn Point）」為圓心**計算半徑距離。此舉可避免多人連線衝突與重進刷新後的座標錯亂。
   * 離降落點越遠，遇怪率、怪物強度、寶箱品質與特殊房間（如紅室）生成率同步提高。
3. **防洗層與防逃課規則**：
   * **核心素材產地綁定**：Depth 只放大掉落數量、星級品質與該層限定深層大獎，**不會**讓低階樓層掉出其他主題樓層的專屬材料（例如在 Depth 50 的 Level 0 永遠開不出魔法森林或地獄的專屬核心）。
   * **反覆橫跳衰減**：若玩家短時間內在同兩個 Level 之間連續來回切換，停止增加 Depth 並觸發空間不穩定懲罰（怪物強化但掉落率下降）。

### 2.3 死亡懲罰、撤離與中繼站（Extraction Loop）
* **死亡懲罰**：在後室死亡會**噴光背包與裝備欄內所有物品**（以下兩項除外）：
  1. **永久金錢帳戶**：綁定玩家資料，死亡或回主世界皆不重置。
  2. **次元保險箱（Secure Container）**：隨身保護格（初始 1 至 2 格，可於主世界高價擴容至 6 格），死亡時箱內物品安全帶回主世界。
* **返回主世界方式**：
  1. **固定出口**：抵達特定安全樓層或稀有樓層尋找返回主世界的門。
  2. **一次性緊急撤離道具**（如「單向歸鄉錨釘 / 歸鄉懷錶」）：於超大型合成台製作，使用時需原地讀條 10 秒（期間吸引周圍實體圍攻），成功後攜帶全身戰利品撤回主世界。
* **中繼站（Safe Hub Levels，如 Level 4、Level 11）**：
  * 安全區域，設有流浪 / 黑市商人、任務板、簡易修復台。
  * **單向寄物箱**：花費金錢將背包物資寄回主世界倉庫，讓玩家不中斷高 Depth 紀錄繼續往深層推進。
  * **付費服務**：單趟裝備保險（死亡自動寄回主世界）、付費捷徑（賄賂嚮導傳送至曾解鎖的深層區域）。

## 3. 角色成長、多資源條與戰鬥系統

### 3.1 獨立等級與經驗值
* **移除 / 隱藏 Minecraft 原版經驗條與原版附魔經驗消耗**。
* 建立獨立的**「探索者等級（Explorer Level）」**。
* **經驗來源**：擊殺實體、合成物品、跨越新層數、首次抵達未探索過的 Level 或稀有 Level、完成商人任務。

### 3.2 三條獨立生存資源（自訂 HUD）
1. **血量（HP）**：保留原版生命值。部分詛咒類或重型近戰武器每次揮擊會**消耗血量**換取高爆發。
2. **飽食度（Hunger）**：**完整保留原版飢餓系統**，增加長期探索的物資攜帶壓力。
3. **理智值（Sanity / SAN）**：**獨立撰寫的新數值條（絕不佔用飽食度）**。處於黑暗、深層環境或異常區域會持續流失；法杖與異常科技武器施法會**消耗理智值**。
* **資源不足判定規則（關鍵）**：當玩家當前血量或理智值不足以支付武器消耗時，**不會強制扣至死亡或附加懲罰 Debuff**，而是直接鎖定攻擊並於 HUD / 音效提示「資源不足，無法使用」，迫使玩家動態切換武器或即時補給。

### 3.3 基礎四維屬性與隱藏屬性
升級獲得自由配點。**所有玩家不論配點皆可裝備任何武器**，不設硬性職業穿戴限制：

| 屬性 | 核心加成效果 | 設計平衡重點 |
| :--- | :--- | :--- |
| **力量 (STR)** | 近戰傷害、擊退距離、負重與重武器揮速 | 強化貼臉抗壓與重型武器手感 |
| **敏捷 (AGI)** | 移動速度、衝刺體力減耗、遠程武器（槍械 / 弓弩）**裝填速度、後座力控制 / 精準度、暴擊率** | 遠程武器本身基礎傷害已高，敏捷強化「操作手感與爆發上限」而非直接膨脹單發白字 |
| **體質 (VIT)** | 最大血量、自然回血速度、負面狀態抗性（流血 / 中毒持續時間縮短） | 提升容錯率與支撐耗血近戰武器 |
| **理智 (SAN)** | 最大理智上限、安全區理智回復速度、法杖類武器理智消耗減免 | 支撐法術輸出與深層抗精神污染 |

* **隱藏屬性解鎖系統（卷軸擴充）**：
  * 介面與資料結構需支援動態新增屬性列。玩家透過稀有寶箱或 Boss 掉落獲得**「禁忌知識卷軸」**使用後，永久解鎖新屬性欄位並可於升級時加點。
  * 預計擴充欄位：**幸運 / 洞察 (LUCK)**（提高敲家具稀有掉落、寶箱品質與任務報酬）、**靈能 / 抗性 (PSY)**（減緩環境掉理智、強化法術範圍）、**工程 / 巧手 (TECH)**（槍械機率免耗彈、提升拆解產出與儀器效能）。

### 3.4 預留擴充項（目前歸類為「暫不實作 / 後期可選」，僅預留資料接口）
> **給 Claude Code 的指令**：以下兩項目前列為 **Phase 2+ 可選功能（暫不優先開發）**，但底層玩家資料與武器 NBT 結構需先預留擴充欄位，避免未來重寫。

* **職業系統 / 流派執照（Badge 替代方案）**：為避免傳統職業限制配點造成後期悔恨，若日後實作，優先以「可切換的流派徽章（Curios 欄位）」呈現被動效果（例：法杖減耗、近戰耗血減半）。
* **成長型本命專武（Signature Weapons）**：中期擊敗特殊樓層 Boss 取得素材後，於主世界商人兌換、綁定個人且有等級門檻；可隨擊殺或特定祭壇持續升階、鑲嵌強化（替代原版附魔系統），升階後切換發光 3D 模型與解鎖專屬主動技能。

## 4. 經濟、任務與 300+ 樓層規劃

### 4.1 永久金錢與黑市貿易
* **致富途徑**：收集廢料與稀有物資、透過超大型合成表或主世界機器加工成高溢價商品（加工後售價為原料總和的 3 至 5 倍）賣給商人、完成懸賞與跑腿任務。
* **深度商店分級**：越深層的中繼站商人販售越頂級商品（現代槍械、高階彈藥、特殊屬性卷軸、高階藍圖）。頂級軍火與神裝可採用「**大量金錢 + 該層稀有素材**」雙門檻，防止前期刷錢直接買穿後期。

### 4.2 跨層任務系統
* **任務類型**：討伐指定 Level 的小怪或 Boss、收集 / 合成指定物品交付、**跨多層連續送信**（進階條件：不回主世界的前提下連續穿越多個指定 Level 交貨）。
* **防死局演算法（必做）**：隨機派發任務時，任務生成器必須過濾玩家「已解鎖圖鑑 / 已持有鑰匙卡或駭客器等級」可抵達的樓層池，嚴禁指派無法進入的封鎖樓層。

### 4.3 300+ 樓層架構與主題分類
參考 Backrooms Wikidot、Fandom 與《胡霖的後室》規劃 300 個以上樓層，並納入原版衍生與跨界彩蛋層（Minecraft 地獄層、終界層、侏羅紀層等）。

* **效能架構策略（防記憶體爆炸）**：
  * **嚴禁建立 300 個獨立 Minecraft Dimension**。將風格相近的樓層整合至少數維度中，透過**超大座標分區（每區隔 10,000+ 格並限制邊界）或自訂區塊生成器 + 生物群系（Biome）切換**來隔離不同 Level。
  * 分層開發：**30 至 50 個核心主題層**精細設計結構與 Boss，其餘 250+ 層透過**資料驅動樓層引擎**組合「地形骨架 + 方塊替換表 + 家具掉落池 + 實體池」批量擴充。
* **主題資源分工（各司其職）**：
  * **Level 0（大廳）**：純粹的辦公雜項、家電回收、基礎求生與陽春醫療。
  * **工業 / 倉庫層（Level 1, 2, 3）**：重金屬、管線、火鹽、工業機械與中階彈藥素材。
  * **醫院層**：高階醫療包、正規止痛藥、嗎啡、手術組件。
  * **礦坑層**：高密度自訂礦物、金屬冶煉與鍛造素材。
  * **魔法森林層**：魔導植物、法術核心、消耗理智的強力法杖與卷軸。
  * **叢林層**：高階異變植物、稀有草藥、劇毒與高級有機素材。
  * **稀有實驗室層**：高階黑科技與**刻意偏向 OP（不強求絕對平衡）的強力實驗武器**。
  * **異界聯動層（地獄、終界、侏羅紀等）**：終局核心素材、保險箱擴容料、神裝鍛造核心。
* **特殊樓層解鎖條件**：鑰匙卡（消耗品）、**多階密碼門駭客器 Tier 1 至 Tier 4**（永久升級道具，借鑒《非生物因素》）、完成該層機關任務（修發電機等）、或特定商人任務解鎖。

## 5. 多遊戲融合合成與加工系統

### 5.1 超大型蜘蛛網合成台（核心特色）
* 採用 $7 \times 7$ 或 $9 \times 9$ 網狀合成介面。
* **配方結構邏輯**：
  * **中心點**：後室稀有核心（Boss 掉落物、切出裂片、濃縮杏仁水）。
  * **內環**：後室功能零件與工業中間產物（電路板、計算磚、實體掉落物）。
  * **外環**：**Minecraft 原版物資**（鐵錠、紅石、銅錠、黑曜石、終界珍珠、玻璃瓶、紫水晶等），象徵以現實物理結構固定異常能量，確保原版資源全程保有高價值。

### 5.2 四大借鑒子系統整合
1. **星級品質系統（《星露谷》 / 《異星工廠 2.0》）**：
   * 物品具備 NBT 品質標籤：**普通（Normal） -> 銀星（Silver） -> 金星（Gold） -> 紫星（Anomalous）**。
   * 品質影響：消耗品回復與 Buff 倍率、貿易品售價（紫星最高翻 3 倍）、用於合成裝備時的面板加成。
2. **工業零件與研究樹（《異星工廠》）**：
   * **基礎零件**：齒輪、銅線圈、鋼板（廢金屬 + 煤炭）。
   * **三色電路階梯**：綠板（Level 0 基礎電路） -> 紅板（中層塑膠 + 綠板） -> 藍板（深層酸液 + 紅綠板）。
   * **研究瓶（Science Packs）**：黃瓶（大廳）、灰瓶（軍事）、紫瓶（空間）投入主世界研究終端，穩定解鎖蜘蛛網高階配方。
   * **插件晶片**：速度、產能、節能 / 穩定晶片，可插於主世界加工機或特定儀器 / 武器插槽。
3. **科技積木與拆解分級（《非生物因素》）**：
   * **標準積木**：電源磚（Energy Brick）、計算磚（Computation Brick）、控制器（Controller），避免大合成表塞滿零散垃圾。
   * **工具分級拆解**：前期徒手 / 普通工具敲爆家具掉基礎碎片；中後期使用「精密拆解螺絲起子」拆同一家具，可無損取出完整風扇、電源供應器，甚至打包完整檔案櫃帶回主世界當倉庫。
4. **加工致富與收集包（《星露谷》）**：
   * **異常蒸餾桶**：將杏仁水、草藥釀造為「陳年精釀杏仁露」（高回理智 / 高暴利賣商人）。
   * **垃圾回收機**：將破布、塑膠、鏡片自動轉化為純淨鋼錠、銅線或機率產出電池。
   * **異常晶體複製機**：後期設施，緩慢複製單顆極稀有晶核（如火鹽、切出裂片）。
   * **異常檔案修復板（Bundles）**：繳交各層指定物資組合，永久解鎖系統便利功能（開局補給箱、快捷傳送、探測加成）。
   * **封存盲盒（Geodes）**：敲檔案櫃掉落「鏽死辦公保險箱 / 加密硬碟」，帶回主世界付費請商人開啟抽古物、舊幣與卷軸。

## 6. Level 0（大廳）MVP 詳細物資與場景規格

Level 0 定位為**「辦公雜項、家電回收與入門求生層」**，共計 **29 至 30 種基礎物資**。

### 6.1 結構保護與 3D 可破壞家具池
* **不可破壞方塊**：黃色壁紙、潮濕地毯本體、輕鋼架天花板（防止挖牆逃課）。
* **可破壞 3D 物件（分單體與 $2 \times 2$ 雜物山）**：
  * **椅類與雜物山**：倒扣折疊椅堆、穿模卡牆辦公椅、斷腿木椅（$2 \times 2$ 雜物堆敲碎連續噴出 3 至 5 種隨機材料）。

## 7. 美術品質、效能優化與工程規範（Claude Code 必守鐵律）

### 7.1 美術與效能紅線（解決 Level 0 粗糙與卡頓問題）
1. **嚴禁使用 `512x512` 方塊貼圖**：所有建築方塊與 3D 家具貼圖解析度**統一鎖定為 `32x32` 或 `64x64`（最高不超過 `128x128`）**，維持一致的像素密度並確保跑圖 FPS 穩定。
2. **質感來源改用 PBR 與環境渲染**：
   * 為基礎建材（壁紙、地毯、金屬）搭配法線貼圖（`*_n.png`）與高光粗糙度貼圖（`*_s.png`）以配合市面光影包。
   * 強制維度霧氣渲染：Level 0 視野霧氣限制在 **24 至 32 格**（昏黃微霧），同時提升效能與恐懼感。
   * 環境音：日光燈 60Hz 低頻電流底噪、燈管閃爍音效。
3. **電影級建築比例標準（重構 Level 0 必備）**：
   * 走廊寬度至少 **3 至 5 格**，天花板高度 **4 至 5 格**（拒絕 1 格窄廊與 2 格矮房）。
   * 牆壁採三段式細節：底層深色踢腳板（Baseboard）+ 中層 3 至 4 種隨機污漬變體黃壁紙 + 頂層收邊線板（Crown Molding）。
   * 天花板使用立體輕鋼架模型，搭配獨立懸吊式 3D 日光燈管（設定 10% 熄滅、5% 閃爍）。
   * 房間生成採用 **Jigsaw 模組化拼圖系統**（預製 10 種以上標準大廳、柱陣、隔間、雜物室拼接）。
4. **3D 模型工作流與授權提醒**：
   * 複雜 3D 家具（電腦、沙發、電視）透過 **Blockbench** 製作並匯出 `.json` / `.geo.json`，避免純手寫複雜幾何座標導致歪斜；擺放時可刻意套用 $22.5^\circ$ / $45^\circ$ 旋轉與輕微碰撞箱重疊製造電影感「穿模家具堆」。
   * 若參考或借用開源專案 `SpacePotatoee/MinecraftFoundFootage` (`spb-revamped`) 的資產，須嚴格遵守其 **GPL-3.0 / LGPL-3.0** 標註原作者與開源義務；且需注意其原生渲染依賴 Fabric 1.20.1 的 Veil 引擎（與 Sodium / Iris 不相容）。

### 7.2 程式碼架構與資料驅動規範
1. **禁止硬編碼堆砌 Class**：必須為武器、道具與家具建立**資料驅動的通用父類模板**：
   * `SanityStaffItem`（統一處理理智扣除與不足鎖定提示）
   * `BloodMeleeItem`（統一處理血量扣除與不足鎖定提示）
   * `CustomGunItem`（統一掛鉤敏捷 AGI 的換彈速度、後座力與暴擊率）
   * `BreakablePropBlock`（統一處理工具分級拆解、穿模堆疊、品質掉落表）
2. **全面使用 Item Tags**：所有合成配方優先引用統一物品標籤（如 `#backrooms:electronics`、`#backrooms:scrap_metal`、`#backrooms:office_junk`），確保日後擴充至 300 層時新素材無痛接入既有合成系統。
3. **Player Capability / Data Attachment 同步**：確保以下自訂數據在 Server 與 Client 端完整持久化與即時同步：
   * `ExplorerLevel`, `ExplorerXP`
   * `Attributes (STR, AGI, VIT, SAN, unlockedHiddenStats[])`
   * `CurrentSanity`, `MaxSanity`
   * `PermanentMoney`
   * `SecureContainerInventory`
   * `CurrentDepth`, `CurrentLevelId`, `CurrentEntrySpawnPos`
   * `VisitedLevelsSet`, `UnlockedRecipesSet`
