# 主樓層可破壞與收集物規劃（第一版，2026-11-24）

使用者的方向：每一層有自己能打掉、能收集的東西。像第 0 層什麼都可能有（電腦、手機、椅子、沙發……），敲掉會掉出**對應的物品**；同一種東西有完好的、壞掉的、**穿模的**版本；還有玻璃，之後在特定樓層（例如 Level 13 玻璃瘋狂）拿到稀有玻璃，Level 39 魔法森林拿到魔法材料。

這份只規劃**目前已經做好的樓層**：0、0.1、1、2、3、4。還沒做的樓層，等做到時再照同樣的格式補。

材料的名稱沿用 Gemini（Antigravity）的 [材料.md](材料.md)，兩邊不另取新名字；這份補的是「每一層擺什麼、敲掉掉什麼」。

## 一、三種掉落方式

| 種類 | 敲掉之後 | 例子 |
|---|---|---|
| **結構**（牆、地、天花板、燈） | 拆成材料（照 Gemini 的拆解表） | 壁紙 → 受潮碎壁紙、石膏粉；日光燈 → 燈管碎玻璃、紅銅線 |
| **物件**（家具、電器、雜物） | **掉出物品本身**，可以帶走、放回去、或在拆解台（Gemini 的 `salvage_bench`）拆成材料 | 電腦 → 「電腦」物品；沙發 → 「沙發」物品 |
| **異常物件**（穿模、發光、會動的） | 掉出「異常版」物品；要更好的工具；拆開有機會出異常材料 | 穿模的電腦 → 「穿模的電腦」，拆解小機率出 `reality_fragment` |

**同一種物件的三個版本**（以電腦為例）：

| 版本 | 樣子 | 多常見 | 拆解產出 |
|---|---|---|---|
| 完好 | 正常擺著 | 常見 | 最多、最完整 |
| 損壞 | 螢幕破、外殼凹 | 常見 | 少一些 |
| 穿模 | 一半卡進牆／地毯、貼圖閃爍或錯位 | 稀有 | 普通材料少，但有機會出異常材料 |

**層數越高，越稀有**：配合新的「第幾層」系統（見 [遊戲玩法：層數與難度](../1-遊戲玩法/README.md#在後室裡層數與難度)），走得越深，穿模版本和稀有材料出現的機率越高。

**分工**：
- Claude：決定每一層擺什麼、擺多少、擺在哪（樓層生成），以及敲掉掉什麼（掉落表）。
- Gemini：新物件與新物品的 3D 模型、貼圖，拆解台和合成表裡怎麼用。

#### 6.3 Level 0 寶箱分層與實體規則
* **淺層寶箱（Depth 1 至 10）**：杏仁水、罐頭、破布、繃帶、少量舊幣、原版基礎材料（線、木棒、鐵粒、銅錠、煤炭、玻璃瓶、低耐久工具）、低機率出「生鏽樓梯間鑰匙」。
* **深層回歸寶箱（Depth 30 以上）**：高星級濃縮杏仁水、急救包、大量金錢、原版紅石塊 / 青金石 / 金蘋果 / 終界珍珠 / 附魔書、切出裂片、高階藍圖殘頁。
* **實體分佈**：近處淺層以極低密度「菌體」營造孤獨壓迫感；水平遠處或高 Depth 混入「獵犬（掉獵犬長牙）」、「笑魘（掉發光眼珠 / 暗影精華）」與精英菌體。
* **特色 POI（紅室）**：水平遠離降落點低機率生成，紅光扭曲、高理智流失、必刷精英怪，固定含 1 至 2 個高階寶箱與稀有出口。

## 十、做的順序

1. 第 0 層：新物件（電腦、手機、沙發、玻璃隔間、完好辦公椅）請 Gemini 先做模型；同時我把 Gemini 已做好的 24 種穿模家具裡屬於第 0 層的先擺進去。
2. 第 1、2、3 層：先補「新規則」的掉落表，再擺 Gemini 的穿模家具。
3. 第 0.1 層：觀景玻璃改成可拆、補電子零件掉落。
4. 掉落的稀有度跟「第幾層」掛鉤（見 [遊戲玩法：層數與難度](../1-遊戲玩法/README.md#在後室裡層數與難度)）。
