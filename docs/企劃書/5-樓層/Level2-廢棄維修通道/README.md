# Level 2：廢棄維修通道（Abandoned Utility Halls）

- **狀態**：已實作（第一版）
- **程式**：`src/main/java/dev/noclip/backrooms/level2/`（入口是 `Level2.java`）
- **維度**：`noclip_backrooms:level_2`；出口登記鍵 `"2"`（Level 1 往下的樓梯會接到這裡）
- **貼圖與模型**：`textures/block/level2/`、`models/block/level2/`，由 `tools/make_level2.py` 產生；預覽在 `docs/企劃書/5-樓層/Level2-廢棄維修通道/textures.png`
- **參考來源**：[Wikidot Level 2](http://backrooms-wiki.wikidot.com/level-2)（文字與 13 張照片）。Fandom 那邊叫「Pipe Dreams」，兩邊都是滿是管線的混凝土維修通道。
- **直接進入**：先到 Level 1（`/execute in noclip_backrooms:level_1 run tp @s 32.5 33 41.5`），找往下的樓梯；或在測試世界用 `/execute in noclip_backrooms:level_2 run tp @s 2.5 33 2.5`（落點不一定在走道上）

## 照 Wiki 做了什麼

| Wiki 的描述 | 遊戲裡 |
|---|---|
| 無限延伸、通常又窄又擠的維修通道，長度大約是 5 公尺的倍數，轉彎都是 45 度 | 迷宮由 5×5 格的單元組成，走道寬 3 格、高 4 格，喜歡一直往前延伸；轉角外側切掉一格，看起來像斜角 |
| 機器和管線從地板鋪到天花板，蓋住一邊或兩邊的牆 | 直走道的一側整排是管線：最下面是包覆保溫管或淡綠大管，中間是生鏽鋼管和紅管（偶爾有紅色閥門、漏水），上面是電纜槽和細管。只剩 2 格寬可以走，擠不過去 |
| 機器隨意擺放、很少運作，發出故障般的低鳴 | 管線排的盡頭是機器櫃和儀表板，偶爾低鳴 |
| 牆是乾枯、髒汙、會沾一手粉的混凝土，有些區段是泥褐色或黑色的磚 | 牆面依區塊分成粉狀混凝土（有些剝落、有水痕）、泥褐磚、黑磚、白漆磚 |
| 日光燈稀疏、分布不均，有白色和橘色；線路是串聯的，壞一盞整組都熄；停電後零星亮起紫色緊急燈 | 每個單元中間一盞燈，3×3 個單元是一個電路。約 30% 的電路整組是暗的，有些在中間亮著紫色緊急燈；磚牆區用護網燈泡。**打破一盞燈，同電路的燈全部熄滅** |
| 有些區域熱得不合理，Level 127 的出口就在那裡；另有極寒與毒氣洩漏區 | 約三分之一的區域有悶熱區（飢餓、虛弱）；另有極寒區（緩速、結霜）與管線爆裂毒氣區（反胃、中毒、煙霧粒子） |
| 辦公室風格走廊與空間迴圈 | 部分 4×4 區塊為沒有任何管線的白漆磚「辦公室走廊」，死路盡頭偶爾會把玩家傳回走廊前段（「回到原門」現象） |
| 白色／灰色／米色的鋼門，有方格浮雕、鎖、警告標示；很多是鎖住的；門後是空房間、堆滿雜物的倉庫、機器間，或什麼都沒有的「虛無房」 | 每個區域有 2～4 個房間（空房、放有木箱／油桶／工具箱／電線盤／木材垛的倉庫、整排機櫃的機房、全黑的虛無房、B.N.T.G. 辦公區 EL3A、Macchina 遺跡），走道死路角落也偶爾散落工具箱、電線盤與木材垛，門可開或鎖住（EL3A 與 Macchina 一律不鎖） |
| 辦公區 EL3A 與窄軌鐵路 | EL3A 為安全區（無悶熱與怪物），內有工作台、儲物箱、提燈、木箱機櫃與 B.N.T.G. 駐員；EL3A 所在區域的長直走道會拆除管線鋪設窄軌鐵道（含動力鐵軌與貨運礦車） |
| 機巧子民（Macchina）遺跡 | 黑磚地面與銅塊／靈魂燈籠祭壇、講台與古老機械殘骸 |
| 窗戶（Entity 2）：偶爾出現在走道盡頭，嚴禁靠近 | 死路盡頭偶爾有一扇亮得像白天的窗。靠近會聽到敲玻璃聲，太近會被拖過去受傷並陷入黑暗 |
| 常見實體：獵犬成群出沒，大停電後微笑者等實體活躍 | 待在暗處時偶爾會有兩隻獵犬從後方追上來；另外依明暗環境會生出微笑者、爬菌、死亡飛蛾、肢團、無面靈、悲尸、竊皮者（`Level2Monsters`） |
| 一般出口（往 1、3、4）常有前人留下的記號或刻字 | 這三種門附近 7 格內的直走道牆上，有前人用紅色噴漆寫的樓層號和箭頭，順著箭頭走就到得了那扇門 |

## 場景細節

- 走道牆上：配電箱、壓力表、黃黑警告牌（悶熱／極寒／毒氣區只有警告牌與壓力表；不會掛在錯位牆上）
- 地板：潮濕區的排水格柵、直走道一側的地板電纜槽；積水路段外圈是積水地板，中間是半格深的淹水石板（踩得過去，不會卡在溝裡）
- 天花板：通風口、垂下的斷電纜、跨走道的高架管橋（積水處的會漏水）
- 極寒區有結霜的牆、地板與管線，毒氣區有破損噴氣管
- 三種磚牆（白漆、泥褐、黑）各有四種畫法（磚的深淺、剝落、泥污、煤灰位置不同）每格隨機挑一種（沒用鏡像：同一張和自己的鏡像相鄰時，剝落會變成左右對稱的蝴蝶形）
- 一般牆、地板、天花板每格隨機轉向或鏡像，工具箱、木材垛、電線盤、廢料堆也隨機轉向，長走道不會一格一格重複
- EL3A 的儲物箱與貨運礦車打開有補給（`loot_table/chests/level2_supplies.json`，內容和停車場補給箱一樣）；EL3A 四角掛提燈；EL3A 與 Macchina 的箱子、講台、機櫃朝向每處不同
- 寫實材質包的磚牆是長方形的順砌磚（以前用的 Bricks075A 照片其實是亂石牆）
- 後加的貼圖補上 labPBR `_n`／`_s`（`tools/make_level2_polish.py`，要在其他 `make_level2*.py` 之後跑；重跑 `make_level2.py` 會蓋掉牆與地板的隨機轉向，要再跑一次這支）
