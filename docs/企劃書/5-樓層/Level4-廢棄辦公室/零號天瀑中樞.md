# 零號天瀑中樞（Atrium Zero / 蒼穹雨井）

- **狀態**：【已實作】（2026-11-28 完成一～三階段，通過 `gradlew build` 單元測試與 `runClientGameTest` 原版／光影雙模式驗收）
- **定位**：Level 4 唯一「**整棟摩天樓替換型**」極稀有宏大奇觀巨景，與既有 20 種房間／翼區級興趣點（[`興趣點.md`](興趣點.md)）區隔，作為改變整場探索記憶的超級地標。
- **核心原則**：大體安全、可安心駐足欣賞並回復理智；唯獨下層底層檢修鋼架依靠真實的高空深淵失足風險，換取傳奇常駐出口與高階物資。

---

## 一、核心意象與空間尺度

- **佔地與高度**：完整吃滿單一 `112×112` 區域（`16×16` 個 `7×7` 單元）內的整棟 `84×84` 格摩天樓本體（單元 `i, j ∈ [2..13]`，區內方塊座標 `lx, lz ∈ [14..97]`），並貫通 Level 4 全維度 `192` 格高度（`y = -64 .. 127`）。
- **善用既有霧氣與雨景**（對齊 `level_4.json`）：
  - Level 4 自帶冷灰白霧（`#cfd7dd`，`fog_start = 16.0`、`fog_end = 62.0`）與常駐下雨。
  - **水平距離**：從外圍玻璃環廊望向中央天瀑與水盤約 `25～45` 格，剛好落在半透明立體霧區，對岸數十層亮燈辦公室與中央水幕呈現朦朧卻清晰的巨物輪廓。
  - **垂直距離**：從主層 `y = 32` 往上延伸 `+95` 格至 `y = 127`、往下掏空 `-96` 格至 `y = -64`，均遠超 `fog_end = 62.0`，抬頭看不見頂、低頭看不見底，在原版與光影下皆自然形成「無頂無底」的無限錯覺。

## 二、分層建築結構與座標規格（對齊 `Level4Plan` / `Level4ChunkGenerator`）

### 1. 外圍全景玻璃環廊與千層立面（中層 `y = 32`）

- **外圈環廊**（單元 `i ∈ {2, 13}` 或 `j ∈ {2, 13}`，共 1 單元寬）：
  - 完整保留四面各 2 條（共 8 條）`skybridge` 空中連廊入口直接接入環廊，**100% 維持跨區連通性**，玩家推門進入後即刻直面中空巨井。
  - 靠巨井內側改為全景落地玻璃護欄（`office_rain_window` / `office_glass_wall`）與 `office_pillar` 柱列。
- **70×70 格開放中空巨井**（`i, j ∈ [3..12]`，區內座標 `lx, lz ∈ [21..90]`）：
  - 整塊中心區域從 `y = -63` 到 `y = 127` 全面掏空（僅保留以下結構與懸浮物件），天頂直接承接雨幕。
- **千層虛假空辦公室帷幕牆**（環廊內壁外推立面，從 `y = -60` 堆疊至 `y = 124`，每 `5` 格一層，共 `30+` 層）：
  - 以 `office_rain_window`（絕不生成陷阱窗）、`office_pillar_upper`、`office_drywall_upper` 構成標準辦公幕牆網格。
  - 內部嵌入稀疏隨機亮度的四態 `office_troffer_*`（亮冷白微綠、昏黃、偶爾閃爍、熄滅），塑造深處永遠亮著燈卻無任何生物的孤寂辦公高樓剪影。

### 2. 中央無源天瀑巨塔與懸浮八角主水盤（中層 `y = 32`）

- **四條無頂玻璃雨橋**：
  - 分別自東西南北四面環廊中軸（寬 `5` 格）筆直延伸至中央水盤；橋面採用透明玻璃地板與低護欄，無天花板遮蔽，行走時可直視腳下深淵並直接淋雨。
- **懸浮八角主水盤**（中心 `lx, lz ∈ [44..67]`，約 `24×24` 格切角八角形浮空平台）：
  - 平台外圈由 `almond_fountain_basin` 承接，內部注滿可安全取水與直接飲用的大型 `almond_fountain_pool`（杏仁水蓄水池）。
  - 中心矗立 `10×10` 格玻璃鋼骨水幕巨塔直通 `y = 127`；無源水流自高空霧中筆直砸落進水盤，再從水盤四邊缺口溢流成四道巨幅水簾，墜入 `y = -63` 白霧深淵。
- **中央乾區觀測台與互動焦點**：
  - 水盤中心島設有乾燥的觀測平台，放置 **M.E.G. 先遣隊觀測銘牌**（規劃新增 1 個焦點互動方塊 `atrium_zero_plaque`）。
  - 右鍵銘牌可閱讀先遣隊日誌（「無人機上飛三公里、鋼纜下放三公里皆只有雨聲與白霧，無頂無底」），並可領取一次性高純度杏仁水補給（如 `purified_almond_essence` 或 `almond_water`，透過 `SavedData` 記錄領取狀態防止重登重複刷取）。

### 3. 半空懸停觀光電梯群

- 在巨井四個象限的懸空區域垂掛貫通上下的垂直鋼纜（`IRON_BARS` / `CHAIN`）。
- 於錯落高度（預設 `y = 19, 43, 54, 66`）各懸停一座 `5×5×5` 透明玻璃觀光電梯廂（使用 `office_elevator_frame`、`office_glass_wall` / `office_rain_window`），內部點亮微弱 `office_troffer_dim` 或 `office_troffer_flicker`，呈現如時間凍結般的視覺對比。

### 4. 上層高空觀景環廊（`y = 48`）

- 環廊對角兩側（如西北、東南角）設有開放式玻璃折返階梯，可從主層 `y = 32` 攀登 `16` 格抵達 `y = 48` 上層觀景環廊。
- 環廊提供俯瞰中央天瀑、四條雨橋與懸停電梯的極佳拍照／觀景視角。
- 其中一角保留 M.E.G. 先遣隊測繪營地遺址，沿用既有 `office_supply_crate`、`office_steel_safe`、`camp_sleeping_bag` 等方塊（透過 `SavedData` 控制一次性搜刮）。

### 5. 下層水盤底層檢修鋼架（`y = 18`）— 高風險高回報區

- **進入方式**：從中央八角主水盤一側，沿著懸空的窄金屬檢修梯／階梯垂降 `14` 格至 `y = 18`，進入懸吊在水盤正下方的底層檢修平台。
- **空間危險設計**：
  - **不靠刷怪**製造壓迫，而是依靠窄金屬格柵走道、斷裂低護欄與強烈的高度差，帶來真實的**高空深淵失足風險**；頭頂是巨大水盤底板，四面則是震耳欲聾、垂直墜入深淵的四道瀑布水簾。
- **盡頭回報**：
  - 檢修架最深處固定設有一座 `office_steel_safe`（高階零件與物資）以及一扇**永不消失的傳奇常駐出口**（沿用既有 `Level4Exit` 體系，預設規劃為常駐 `CITY_DOOR_11` 或 `STAIRS_5`，不受 `Level4VanishingExits` 轉身消失規則影響）。

## 三、生成稀有度、防衝突與氛圍規則

- **極稀有確定性分布**：
  - 採用類似 `OMEGA_SPREAD` 的巨型方格保底確定性演算法：每 **`12×12` 區域（144 棟大樓）僅生成 1 棟**（機率約 `0.7%`）。
- **強制安全避讓**：
  - 嚴格避開出生區域 `(0, 0)` 及其周圍半徑 1 格區域（`rx, rz ∈ [-1..1]`）。
  - 與 `OMEGA_BASE`、`AMOR_CAMP`、`TBD_ROOM` 完全互斥；若候選座標剛好命中 Omega 基地所在區域，則在同一 `12×12` 區塊內確定性順移至下一個不衝突的區域。
- **安全與氣氛規則**：
  - **禁生敵對怪物**：整棟區域停用 `Level4Monsters` 自然生怪，且所有外窗與井壁皆使用 `office_rain_window`（**絕對不生成 Entity 2 陷阱窗**）。
  - **音效切換**：踏入奇觀區域後，停止原本令人煩躁的 60Hz 空調嗡鳴與幻聽腳步聲，改為低沉遼闊的巨瀑與高空雨聲回音（沿用／擴充 `Level4Sounds.RAIN` 與低音水聲）。
  - **理智回復**：玩家站在中層主水盤或上層觀景環廊停留時，理智值會隨時間緩慢回復。

## 四、材質重用與實作分期計畫

### 1. 方塊與材質規劃

- **95%+ 重用既有方塊**（無須大量重畫貼圖，亦無方塊 ID 撞名風險）：
  - 結構與幕牆：`office_rain_window`、`office_glass_wall`、`office_pillar`、`office_pillar_upper`、`office_drywall_upper`、`office_troffer_lit` / `dim` / `flicker` / `broken`、`office_elevator_frame`。
  - 水景與據點遺址：`almond_fountain_basin`、`almond_fountain_pool`、`office_supply_crate`、`office_steel_safe`、`camp_sleeping_bag`、原版鐵欄桿／鎖鏈／樓梯。
- **唯一建議新增方塊（1 件）**：
  - `atrium_zero_plaque`：M.E.G. 先遣隊觀測銘牌（128px 結構面／64px 道具或方塊模型規格，附 `realistic` 包 labPBR `_n`/`_s` 貼圖，實作前先確認無 ID 撞名）。

### 2. 建議實作分期與驗收基準

1. **第一階段（規劃與骨架生成）**：
   - 在 `Level4Plan` 加入整棟奇觀區域標記與 `12×12` 確定性互斥選點；在 `Level4Layout` 與 `Level4ChunkGenerator` 實作外圍環廊、8 條 `skybridge` 對接、千層玻璃井壁、中央八角水盤、四條雨橋與水瀑塔。
   - **驗收**：`Level4LayoutTest` 確認所有連廊與內部區域 100% 連通、不與據點重疊。
2. **第二階段（立體分層與懸浮細節）**：
   - 補齊上層 `y = 48` 觀景環廊與折返梯、下層 `y = 18` 檢修鋼架與常駐傳奇出口、四角懸停觀光電梯群，以及 `atrium_zero_plaque` 方塊與雙模式（原版／寫實包）貼圖。
   - **驗收**：`.\gradlew.bat build --no-daemon` 全部通過。
3. **第三階段（互動事件、音效與實機光影驗收）**：
   - 接入 `SavedData` 一次性補給、銘牌互動、理智緩慢回復、巨瀑雨聲回音與禁怪／禁陷阱窗規則。
   - **驗收**：執行 `.\gradlew.bat runClientGameTest -Plevels=4 --no-daemon` 與 `-Pshaders`（Iris + `ComplementaryUnbound_r5.10_Backrooms`），於實機截圖確認高空霧景層次、無破牆／斷橋／穿模／缺貼圖或異常光影溢色。
