# 畫面風格規範（第一版，2026-11-25）

給所有做樓層、方塊、道具、模型的人（Claude、Gemini／Antigravity、朋友）共用。目的是幾百層做下來，**每一層都像同一個遊戲**，而且夠精緻。做每一層的步驟見 [SOP.md](SOP.md)。

## 一、目標

- **找到的錄影帶**（found footage）那種寫實後室：髒、舊、潮濕、安靜，光只照得到燈附近，遠處沉進黑暗。
- 參考來源：Backrooms wiki 的照片、Kane Pixels 的影片、[Minecraft Backrooms Found Footage](https://modrinth.com/mod/minecraft-found-footage) 的遊戲畫面。**只參考，不拿**：別人的貼圖、模型、音效一律不放進來（授權問題見 [README.md](README.md)）。
- **兩種玩法都要好看**：
  1. 不開光影：靠我們的攝影機濾鏡（F7）、黑霧和光的衰減。
  2. 開光影：Iris＋Complementary，用 [`shaders/`](shaders/) 裡的推薦設定。光影包由玩家自己下載，我們**只提供設定值**，不附光影包本身。

## 二、材質（貼圖）

| 規則 | 內容 |
|---|---|
| 清晰度 | 方塊每一面 **512×512**（等於模型裡每 1/16 格 32 像素）。道具模型照同樣密度：寬 4/16 格的零件用 128 像素。手拿的物品圖示可以小一點，但放在世界裡的東西都照 512／格 |
| 必附的貼圖 | 每張彩色貼圖都要有 labPBR 的 `_n`（法線＋陰影＋高度）和 `_s`（光滑度、反射率、吸水性、發光），開光影時才會有立體感和反光。用共用工具產生，不手畫 |
| 來源 | 照片素材只用 **CC0**（ambientCG、Poly Haven），寫進 `CREDITS.md`。程式自己畫的也可以。不用別人模組或遊戲的素材 |
| 顏色 | 每層照參考照片取色。不開光影時 Minecraft 的光會把黃色壓成橄欖綠，所以黃色系要往暖一點調 |
| 藏住方塊格線 | 花紋不要剛好一格一個框：天花板一格四片磚、地毯和壁紙無縫、污漬可以跨格。真的有格線的地方（天花板龍骨）才畫格線 |
| 髒舊變體 | 同一種牆／地／天花板做 9 種變體，編號意思全部統一：1 水漬、2 短滴痕、3 長流痕、4 手抹的髒污、5 補丁、6 起泡、7 破洞、8 黴、9 斑點。變體只在少數格子出現，整體要乾淨到看得出原本的花紋 |

## 三、模型

| 規則 | 內容 |
|---|---|
| 比例 | 1 格＝1 公尺，照真實尺寸：門高 2 格、桌高 0.75 格、天花板 2.5～3 格、插座在 0.3 格高 |
| 格式 | 方塊道具用 JSON 方塊模型（Blockbench 或 Blender 產生都可以）；生物用 BoxRig（獵犬那一套） |
| 三種版本 | 可以拿走的物件做「完好／損壞／穿模」三種（見 [`docs/levels/MATERIALS.md`](../levels/MATERIALS.md)） |
| 燈具 | 燈不做成整塊發亮的方塊，做成嵌進天花板或掛著的燈具，發亮的那一面用 `light_emission`。每種燈都要有：亮、壞（不亮）、閃爍、快壞（昏黃）四種 |
| 共用零件 | 燈具、管線、通風口、插座、開關、踢腳板、門框、標誌、桌椅這類做一次、很多層共用。某層特有的東西才另外做 |

## 四、光

- 每層一行氣氛設定（`core/look/Look.Mood`）：多遠開始變黑、多遠全黑、光衰減多快。Level 0 的值（霧 3～20 格、衰減 0.38）是目前的基準，使用者看過覺得可以。
- 燈的狀態要混在一起：同一間房就有亮的、壞的、閃的、快壞的。各狀態的比例寫在每層的規格表。
- 光的顏色：辦公室類用冷白偏綠的日光燈照在暖色的牆上，這是「冷」的來源；工業類用鎢絲燈的橘黃；緊急燈用紅。

## 五、光影包

- 推薦設定放在 [`shaders/`](shaders/)，檔名跟光影包同名（`ComplementaryUnbound_r5.10_Backrooms.txt`）。
- `RP_MODE=3`（labPBR）一定要開，光影包才會用我們的 `_n`、`_s`。
- 光影包把我們的維度當成「沒有天空光的洞穴」，最暗的程度由 `CAVE_LIGHTING` 決定，沒燈的地方暗不暗主要看它和 `AMBIENT_MULT`。
- 光影包不讀遊戲本身的霧距離，所以開光影時「看不到遠處」主要靠暗，不靠霧。
- 調設定時兩種都要拍照比對（見 [SOP.md](SOP.md)）。

## 六、驗收

- 每層都要有實機截圖：同樣幾個角度，**不開光影**和**開光影**各一組，跟參考照片並排看。
- 截圖用自動測試拍：`gradlew runClientGameTest -Plevels=N`，加上 `-Pshaders` 就是開光影那一組。

## 八、目前還沒對齊的地方

- Gemini 做的道具與物品貼圖多是 64×64，跟牆面的 512／格差很多，放在一起會一邊細一邊糊。之後的新道具照第二節的密度，舊的再找時間補。
- 共用材質工具（把 `tools/make_level0_realistic.py` 整理成每層填設定就能用）還在做。
