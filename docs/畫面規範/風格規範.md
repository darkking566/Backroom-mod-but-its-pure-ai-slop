# 畫面風格規範（第一版，2026-11-25）

> **2026-11-28 定**：之後方塊貼圖統一 **32 像素**（原因與做法見 [docs/企劃書/5-樓層/README.md](../企劃書/5-樓層/README.md) 的「做到 200 層以上的技術規劃」）。現有貼圖還沒換，換完之前照本文的 128／64。

給所有做樓層、方塊、道具、模型的人（Claude、Gemini／Antigravity、朋友）共用。目的是幾百層做下來，**每一層都像同一個遊戲**，而且夠精緻。做每一層的步驟見 [每層流程.md](每層流程.md)。

## 一、目標

- **找到的錄影帶**（found footage）那種寫實後室：髒、舊、潮濕、安靜，光只照得到燈附近，遠處沉進黑暗。
- 參考來源：Backrooms wiki 的照片、Kane Pixels 的影片、[Minecraft Backrooms Found Footage](https://modrinth.com/mod/minecraft-found-footage) 的遊戲畫面。**只參考，不拿**：別人的貼圖、模型、音效一律不放進來（授權問題見 [README.md](README.md)）。
- **兩種玩法都要好看**：
  1. 不開光影：靠我們的攝影機濾鏡（F7）、黑霧和光的衰減。
  2. 開光影：Iris＋Complementary，用 [`shaders/`](光影設定/) 裡的推薦設定。光影包由玩家自己下載，我們**只提供設定值**，不附光影包本身。

## 二、材質（貼圖）

| 規則 | 內容 |
|---|---|
| 清晰度 | 照規格書 7.1（2026-11-25 起）：**牆、地板、天花板**這類整格的面用 **128×128**；**道具**（家具、燈具、管線、小東西）用 **64×64**；最大不超過 128。不再用 512（太吃記憶體、跑圖會卡）。寫實材質工具可以先畫大張再縮，存檔前一律交給 `tools/resize_realistic.py`（照模型判斷是整格的面還是道具） |
| 必附的貼圖 | 每張彩色貼圖都要有 labPBR 的 `_n`（法線＋陰影＋高度）和 `_s`（光滑度、反射率、吸水性、發光），開光影時才會有立體感和反光。用共用工具產生，不手畫 |
| 來源 | 照片素材只用 **CC0**（ambientCG、Poly Haven），寫進 `CREDITS.md`。程式自己畫的也可以。不用別人模組或遊戲的素材 |
| 顏色 | 每層照參考照片取色。不開光影時 Minecraft 的光會把黃色壓成橄欖綠，所以黃色系要往暖一點調 |
| 藏住方塊格線 | 花紋不要剛好一格一個框：天花板一格四片磚、地毯和壁紙無縫、污漬可以跨格。真的有格線的地方（天花板龍骨）才畫格線 |
| 髒舊變體 | 同一種牆／地／天花板做 9 種變體，編號意思全部統一：1 水漬、2 短滴痕、3 長流痕、4 手抹的髒污、5 補丁、6 起泡、7 破洞、8 黴、9 斑點。變體只在少數格子出現，整體要乾淨到看得出原本的花紋 |

## 三、模型

| 規則 | 內容 |
|---|---|
| 比例 | 1 格＝1 公尺，照真實尺寸：門高 2 格、桌高 0.75 格、天花板 2.5～3 格、插座在 0.3 格高 |
| 格式 | 方塊道具用 JSON 方塊模型（Blockbench 或 Blender 產生都可以）；生物用 BoxRig（獵犬那一套） |
| 三種版本 | 可以拿走的物件做「完好／損壞／穿模」三種（見 [`docs/企劃書/3-合成/各層收集.md`](../企劃書/3-合成/各層收集.md)） |
| 燈具 | 燈不做成整塊發亮的方塊，做成嵌進天花板或掛著的燈具，發亮的那一面用 `light_emission`。每種燈都要有：亮、壞（不亮）、閃爍、快壞（昏黃）四種 |
| 外框與碰撞 | 不是整格的家具，準心外框和碰撞要貼著模型：共用家具與電影家具跑 `tools/make_prop_shapes.py` 從模型算出 `data/noclip_backrooms/prop_shapes.json`（`props/PropShapes` 讀取並依朝向旋轉）；各層自己的方塊寫在各層的 `*Shapes`（例如 `level3/Level3Shapes`） |
| 外框與碰撞 | 不是整格的家具，準心外框和碰撞要貼著模型：共用家具與電影家具跑 `tools/make_prop_shapes.py` 從模型算出 `data/noclip_backrooms/prop_shapes.json`（`props/PropShapes` 讀取並依朝向旋轉）；各層自己的方塊寫在各層的 `*Shapes`（例如 `level3/Level3Shapes`） |
| 共用零件 | 燈具、管線、通風口、插座、開關、踢腳板、門框、標誌、桌椅這類做一次、很多層共用。某層特有的東西才另外做 |

## 四、光

- 每層一行氣氛設定（`core/look/Look.Mood`）：多遠開始變黑、多遠全黑、光衰減多快。Level 0 的值（霧 6～30 格、衰減 0.16，2026-11-28 照程式更新）是目前的基準；各層現在的值見 [README.md](README.md)。
- 燈的狀態要混在一起：同一間房就有亮的、壞的、閃的、快壞的。各狀態的比例寫在每層的規格表。
- 光的顏色：辦公室類用冷白偏綠的日光燈照在暖色的牆上，這是「冷」的來源；工業類用鎢絲燈的橘黃；緊急燈用紅。

## 五、光影包

- 推薦設定放在 [`shaders/`](光影設定/)，檔名跟光影包同名（`ComplementaryUnbound_r5.10_Backrooms.txt`）。
- `RP_MODE=3`（labPBR）一定要開，光影包才會用我們的 `_n`、`_s`。
- 光影包把我們的維度當成「沒有天空光的洞穴」，最暗的程度由 `CAVE_LIGHTING` 決定，沒燈的地方暗不暗主要看它和 `AMBIENT_MULT`。
- 光影包不讀遊戲本身的霧距離，所以開光影時「看不到遠處」主要靠暗；另外 `ATM_FOG_DISTANCE=15`（大氣霧拉近）會在有燈的地方加一層淡淡的霧氣、遠處變朦朧，暗處不會被霧弄亮。洞穴霧的濃度寫死在光影包裡，調不動。
- 目前的推薦值（Level 0 用實機截圖看過）：`RP_MODE=3`、`CAVE_LIGHTING=15`、`AMBIENT_MULT=60`、`DIRECTIONAL_BLOCKLIGHT=7`、`TM_CONTRAST=1.15`、`T_SATURATION=0.85`、`TM_DARK_DESATURATION=0.50`、`BLOOM_STRENGTH=0.16`、`CHROMA_ABERRATION=2`、`ATM_FOG_DISTANCE=15`。彩色光追蹤（`COLORED_LIGHTING`）建議關：它認不得模組的燈，而且很吃效能。開光影的對照圖：[level0_shaders.jpg](level0_shaders.jpg)。
- 調設定時兩種都要拍照比對（見 [每層流程.md](每層流程.md)）。

## 六、驗收

- 每層都要有實機截圖：同樣幾個角度，**不開光影**和**開光影**各一組，跟參考照片並排看。
- 截圖用自動測試拍：`gradlew runClientGameTest -Plevels=N`，加上 `-Pshaders` 就是開光影那一組。
